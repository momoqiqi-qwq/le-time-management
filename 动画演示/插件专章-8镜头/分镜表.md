## 已知偏差（录之前你要知道）

1. **北大这个站的标题字段带正文**。缓存里 `title` 实际是「标题 + 正文」一整段，真机上列表那一行会显示成长文字。动画里用的是干净标题（网站列表页原本的样子）。要不要改插件的截断，是你的决定。
2. **「文字大小」只有滑杆，没有「标准」按钮**——「标准」在下一行「界面缩放」的 小/标准/大 三档里。S7 的做法是：拖「文字大小」滑杆，右上角同时摆「界面缩放」三档，拖回 100% 时「标准」高亮，底部一行小字点明两者分工。口播说「选标准还原」时画面指得到东西。
3. **教务导入的真实点击没做**。浏览器实例里 `tide.schoolImporter.open` 会 reject；这一镜是复刻的学校列表 + 已导入成品课表，数据是真的（38 门课、备注「中国人民警察大学教务导入 · 20262027-1」）。
4. S2 的课表只贴了**第 8 周实际有课的 22 个时段**，底部计数写 38 门课（全学期总数），不是矛盾。
5. 立绘文件夹（`anan - emotion rename/`、`shery - emotion rename/`）约 50 MB，被 `.gitignore` 屏蔽；克隆仓库后按 `动画演示/README.md` 里的命令补齐。

```bash
cd 动画演示/插件专章-8镜头
node build-plugin-tour.mjs            # 重生成 S2-S7（S0/S1 是手写的，不在脚本里）
node build-plugin-tour.mjs s3 s5      # 只重生成指定镜

# 任意毫秒定格截图（虚拟时钟快进）
node ~/.qoder/skills/video-shot-demos/scripts/shot.js shot-s1_学校通知.html 15000 _qc/t.png
```

改画面只动 `build-plugin-tour.mjs` 里对应镜头的 `css / html / cues` 三段；播放器底盘、音效引擎、镜头调度都在模板里，别碰。
