# Le时间管理 v0.11.2

## WakeUp 课表式时间视图
- 时间页新增「WakeUp课表」周视图：7 天列 + 节次/时间行 + 彩色课程块。
- 桌面/Android 优先读取内置「课程表」插件的真实学期、周次、节次、课程、教师和地点数据。
- 未导入课程表时自动使用当前周时间块作为降级数据，不会出现空白页。
- 当前日期所在周自动换算教学周；今天列高亮。
- 宽屏完整 7 列显示，窄屏保持布局并横向滚动，避免课程名称被压扁。
- 微信小程序同步增加 WakeUp 风格周视图，使用本周时间块生成移动端周课表。

## 自定义背景
- 设置新增完整「自定义背景」区域。
- 支持本地 PNG/JPEG/WebP/GIF 图片、纯色背景、启用/停用。
- 支持 Cover、Contain、拉伸、原始尺寸 4 种填充方式。
- 支持九宫格图片定位、横向/纵向/双向平铺。
- 支持固定背景与随页面滚动。
- 支持背景透明度、模糊、亮度、饱和度。
- 支持遮罩颜色与遮罩强度。
- 支持卡片不透明度与毛玻璃强度。
- 支持增强文字阴影。
- 提供实时预览、移除图片、恢复默认。
- 背景图片限制为 6MB，避免本地数据/备份文件异常膨胀。
- 窄屏自动降级 fixed 背景为 scroll，减少 Android WebView 滚动抖动。

## 兼容性
- Windows 与 Android 共用同一前端实现。
- 原有日时间轴、里程碑、横向时间轴、卡片时间轴、年度甘特、阶段甘特全部保留。
