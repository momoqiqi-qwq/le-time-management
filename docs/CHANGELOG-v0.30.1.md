# Le时间管理 v0.30.1

## 改了什么

### 修复：学习通插件在夜间模式下有大片文字看不清

现象（用户反馈）：切到夜间主题打开「学习通」插件，标题「学习通」、导航按钮上的计数胶囊（`4` / `+1`）、底部统计条（「本次新增 1」「平台未读 2」「显示 4 / 共 4」「已移除 1」），以及每条通知的分类标签（作业 / 考试 / 签到 / 通知）都是深色字压在深色底上，几乎看不见。

截图采样确认：标题文字 `#203840`（亮度 27）落在插件页背景 `#141C25`（亮度 27 上下），对比度约 **1.4:1**；统计条文字一度低到 **约 1.5:1**。WCAG AA 对正文要求 4.5:1。

**两个原因叠在一起**

1. **插件自身的样式表是浅色硬编码**（`.cx2{color:#203840}`、`.cx2-pill{color:#275b68}`、`.cx2-kpi` 不给颜色靠继承……）。插件样式由 `ensureStyle()` 在运行时追加到 `<head>` 末尾，与主程序 `.plugview{color:var(--ink)}` 同权重但更靠后，于是 `.cx2` 那行深色把主题色压住了。
2. **主程序的夜间兼容层（`src/styles.css`）是 `!important` 白名单，且只覆盖 `background` 不覆盖 `color`**。`.cx2-pill`、`.cx2-tag`、`.cx2-kpi` 被点名的结果是：底色换成了深色面板色，文字色却留在浅色模式那一套 → 正好凑成最看不清的组合。同一段白名单还把 `.cx2-course.st-*` 的卡片文字色、`.cx2-card.unread` 的青色左边线、`.cx2-new` 的红色「NEW」胶囊一起压掉了。

**改法**

- **`public/plugins/chaoxing-notify/main.js`**：整份插件样式改用主题变量（`--ink` / `--ink-2` / `--ink-3` / `--panel` / `--paper` / `--line` / `--deep` / `--sea` / `--coral` / `--sun` / `--mint`），语义色统一用 `color-mix()` 就地调深调浅。八套主题（暖沙 / fresh / night / ocean / sakura / forest / lavender / mono）自动跟随，不再依赖宿主的兼容层。课程状态四色卡片与状态角标保留原来的红 / 蓝 / 绿 / 灰语义色。
- **`src/styles.css`**：夜间兼容层里移除全部 `.cx2-*` 选择器（插件已自足），只保留 `.gx-*` / `.pp-*`（竞赛消息雷达、警大门户通知仍是浅色硬编码）。**同时修掉同一类问题**：`.gx-tag` / `.pp-tag` 原来只被强制了底色、文字色仍是 `#0F4C5C`（对比度约 1.5:1），现在底色与文字色成对给出，`.pp-tag.top`（金色）/ `.pp-tag.unread`（红色）/ `.gx-tag.n`（紫色）各自保留语义色。

## 影响哪端

桌面端（Windows / Android）与小程序无关（学习通插件在 `platforms.miniprogram` 标为 `unavailable`）。

## 插件版本

`chaoxing-notify` **2.5.0 → 2.5.1**（纯样式修复）。需重跑 `tools/sync-plugins.js` 同步三端 `pluginCatalog.js`。

## 数据迁移

无。样式与配色变更，不涉及 state schema 与本地存储键。
