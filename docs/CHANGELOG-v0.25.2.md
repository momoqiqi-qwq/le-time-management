# Le时间管理 v0.25.2

## 改了什么

### 警大门户 1.4.2：按原版流程显式完成 SSO 换票

- HTTP 会话新增单次请求禁止自动重定向，并把响应 `Location` 返回给插件。
- 密码登录严格按主 SSO 提交、`sso-jw` bridge、门户 ticket、门户 `tp_up` 四段执行。
- 每个一次性 ticket 只消费一次，避免自动跨域跟随后落到桥接端 HTTP 500。
- 仅允许跟随警大三个官方 HTTPS 域名，防止异常重定向离开预期登录链路。
- 浏览器开发桥同步支持上述重定向策略，便于本地回归。

## 影响范围

- Windows 与 Android 共用的 Rust HTTP 会话层、前端 API 层和警大门户插件。
- 无数据结构变化；已保存账号密码与 Cookie 无需迁移。

无。
