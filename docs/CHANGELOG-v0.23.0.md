# Le时间管理 v0.23.0

## 改了什么

### 设置页

1. **移除「设置中心」占位头卡**：纯展示的大横幅（标题 + 三个装饰标签）占掉首屏空间，
   且左侧分类导航本身已承担引导职责，整个删除，打开设置直接看到分类内容。相关 CSS 一并清理。
2. **点击设置卡片外任意位置退出设置**：设置面板此前 `inset:14px` 几乎全屏，可点击的
   遮罩只剩 14px 的边缝，实际等于无法点外部关闭。现在面板四边留出 36px 可见遮罩带，
   点遮罩即退出（Esc 和「关闭」按钮不变）；窄屏（≤900px）仍是全屏模式。

### 自定义背景

3. **新增「组件透明度」滑杆（30–100%）**：此前「卡片不透明度」只作用于 9 种卡面，
   侧栏、顶栏、任务卡（tkc）、迷你卡、设置面板仍不透明，背景透不出来。新增的
   `--custom-comp-alpha` 覆盖这些组件（顶栏附加 6px 毛玻璃），调低即可让背景透出来。
4. **背景图片支持更多格式**：PNG / JPG / WebP / GIF 之外新增 BMP / SVG / AVIF / ICO。

### 插件使用说明（plugin-guide 1.1.0）

5. **修复三个无反应按钮**：
   - 官方网站 / 项目仓库：manifest 此前只有 `ui` 权限，`tide.util.openUrl` 因缺
     `openUrl` 权限静默抛错——补声明权限，并给打开动作加 try/catch 与空链接提示，
     不再无声失败；
   - 项目链接源头修正：`projectLinks.js` 的官网为空、仓库还指向改名前的
     `tidebalance` 仓库——分别改为 GitHub Pages（docs/ 目录发布）与
     `momoqiqi-qwq/le-time-management`（关于页的项目仓库按钮同步修复）；
   - 下载插件开发文档：WebView2 中 blob 下载可能无响应，现在下载的同时把全文
     复制到剪贴板兜底，toast 明确告知；
   - 三个按钮补齐 hover / active 过渡动画（上浮 + 阴影 + 按压缩放）。

## 影响范围

- 桌面端与 Android 端主程序界面 + plugin-guide 插件；小程序不受影响。
- 自定义背景新增 `componentOpacity` 字段（默认 100，老配置行为不变）。

无。
