# Le时间管理 v0.11.4

## 插件中心交互
- 删除插件卡片中的「权限 / 管理」入口与设置页逐项权限开关。
- 插件开启 / 关闭统一使用滑块开关；保留「打开」按钮进入有视图的插件。
- manifest `permissions` 继续作为能力声明和宿主 API 边界，不再保存/应用逐项授权状态。

## 图标
- Windows / Android 共用前端的主导航、插件中心、插件管理切换为 Icons8 / iGoutu iOS Filled 图标。
- 关于页新增 Icons8 / iGoutu 来源入口；Font Awesome 继续用于网页收集插件与微信小程序既有图标资源。

## 通知动效
- 警大门户通知正文展开/收起不再整列表重绘，改为原位 DOM 状态切换。
- 新增高度、透明度、位移、箭头旋转过渡，并支持 `prefers-reduced-motion`。
- 正文异步加载完成后只更新当前卡片内容，减少滚动位置跳动和视觉闪烁。
