# U-Time v0.99.0

## 更新内容

- 新增“警大学分”应用内页面，组合教务培养计划与课程成绩数据。
- 按必修、选修、实践展示目标学分、已获学分、完成进度和课程明细。
- 支持隐藏已修完课程，并记住该显示偏好。
- 创新学分接入申报明细，显示项目名称、项目类别、赛事级别、奖项、认定学分、审核状态和申报信息。
- 移除创新学分页面中无意义的数据库内部字段展示。

## 影响范围

- Windows / Android：警大门户通知插件的学分与创新学分视图。
- 小程序：同步应用版本与插件目录元数据，插件仍标记为不可用。

## 数据迁移

- 无。新数据继续写入现有教务只读缓存。
