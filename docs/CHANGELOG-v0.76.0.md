# v0.76.0

## 改了什么

- 自动更新读取 GitHub Release 资产的 SHA-256，并在下载完成后同时校验文件大小与摘要；校验失败的安装包不会进入安装阶段。
- 最新 Release 若误挂旧版本安装包，现在会禁用自动安装并引导手动下载，避免“安装后仍是旧版、每次启动继续提示”的循环。
- 修复 Windows 重试下载同一版本时旧缓存导致最终重命名失败的问题。
- 新增 `npm run check:update-release` 在线健康检查，核对最新版 Windows NSIS 与 Android universal APK 的文件名、版本号、大小、摘要及真实下载端点。

## 影响范围

- Windows 与 Android 应用内更新链路。
- 小程序仅同步版本号，不涉及更新逻辑。

## 数据迁移

- 无。用户数据与设置结构均未改变。
