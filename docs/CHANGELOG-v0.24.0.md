# Le 时间管理 v0.24.0

## 改了什么

- 将用户提供的时光课程表源码适配为内置课程表插件，采用原版“今日课表 / 课表 / 我的”信息架构。
- 新增多课表的新建、切换、重命名、复制与删除，并兼容原版多课表 JSON 备份恢复。
- 新增全局课程管理、周次选择、课表样式配置及左右滑动切周。
- 保留课程编辑、学期作息、教务表格导入、ICS 导出和 Le 时间块联动。
- 修复移动端格子高度配置被响应式样式覆盖的问题，并支持系统“减少动态效果”偏好。

## 影响范围

- Windows：完整可用。
- Android：完整可用，触控支持左右滑动切周。
- 小程序：插件系统暂不可用。

## 数据迁移

- 首次打开会将旧版单课表数据自动包装为“我的课表”，旧数据不丢失。
- 课程表数据新增 `tables` 与 `currentTableId` 存储项；旧版 `table` 键继续同步保留。
