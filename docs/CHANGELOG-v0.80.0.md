# v0.80.0

## 新增

- “设置 → 界面与交互”新增“应用内打开网页”开关；关闭时沿用系统默认浏览器，开启后普通网页会优先在 U-Time 的独立网页窗口中打开。
- 插件、关于页面、同步帮助、更新说明和局域网页面等普通链接统一遵循这项偏好。
- 全局搜索支持通过“网页、链接、浏览器、内置浏览器、外部打开”等关键词直达该开关。
- Android 新增独立 `BrowserActivity` 承载应用内网页，与教务导入窗口隔离；远程网页窗口不具备主窗口的 Tauri IPC 权限。
- 内置网页窗口创建失败时自动退回系统浏览器，避免链接无法打开。

## 兼容性

- 默认保持原有行为，即使用系统浏览器；只有用户主动开启后才使用应用内网页窗口。
- 仅支持在应用内打开 `http` / `https` 链接，无数据迁移。
