# v0.83.0

## 时间块可拖回任务池

- 日时间轴中的任务时间块现在可以直接拖回左侧任务池；任务池会在拖动期间显示明确接收区，并在指针进入后切换为可放置状态。
- 松手落入任务池后才移除当天排程，关联任务重新出现在待安排列表；操作支持撤销。
- 拖拽取消、指针取消或松手在无效区域时不修改排程，并清理任务池提示状态。
- 回池后的任务卡从原时间块位置播放落位动画；系统或应用启用减少动效时跳过动画。
- 手动创建、没有关联任务的空白时间块不会显示可回池状态，避免误恢复成不存在的任务。

## 顶栏与侧栏工具体验

- 右上角新增设置入口，并纳入顶栏可排序部件及旧存档兼容逻辑。
- 顶栏和左下操作条采用浮起副本、明确空槽和逐项 FLIP 让位动画；支持鼠标、触屏长按、键盘换位和减少动效。
- 左下角窗口缩放按钮在深色模式下统一使用白色图标，包含激活态及拖拽副本。

## 影响范围与兼容性

- 影响桌面端时间块日视图、顶栏及左下操作条；不改变任务或时间块的数据结构。
- 微信小程序仅同步版本号，无数据迁移，不重置现有顶栏排序与任务数据。
