# 微信小程序原生功能对齐 · v0.90.0

日期：2026-09-20

## 交付结论

已在现有仓库完成一轮原生功能补齐，不是桌面网页套壳，也不是只增加不可用按钮。

- 小程序页面：**8 → 11**。
- 内置插件清单：**15 个**；具有原生适配入口的插件：**10 → 13 个**。
- 新增课程表、网页收藏、RSS 信息流的原生页面/适配。
- 增强任务、排程、收件箱、捕获、文件互通和局域网客户端。
- 保留原有 7 种时间视图、已有原生插件、用户存档与额外配置。

原生适配数量不代表 13 个插件都与 Windows/Android 完全等价。联网、系统能力与真机状态单独列明，不承诺不存在的平台能力。

## 功能对照

| 模块 | 本轮小程序实现 | 与桌面/Android 的边界 |
|---|---|---|
| 任务表 | 标签搜索、今日/逾期/未排今日过滤、分页、多选、批量完成/恢复/移动/删除、清理已完成、短时撤销 | 排序采用长按菜单上移/下移及移动象限，不照搬桌面鼠标拖放 |
| 详情 | 即时订阅刷新、自定义分钟、标签、指定日期排程、排程跳转/移除、图片附件 | 新选图片有数量/大小约束；已有桌面附件保留 |
| 排程 | 先校验后替换，仅改选中日期；回池真正移除当天关联块；取消手势不提交；编辑日期/标题/时间/分类 | 采用小程序 movable-view 与原生 picker |
| 时间视图 | 原有 7 种视图保留；有凌晨安排时展开全天；块内点击不冒泡为空白新建 | 未声称与桌面所有像素/动画完全一致 |
| 捕获 | 保留完整原文、手改预览生效、跨天拆分、冲突预检、重复点击保护、暂存收件箱 | 没有系统级跨应用拖拽或全局剪贴板监听 |
| 收件箱 | 读取跨端事项、筛选/分页、转任务保留日期/时刻/附件、处理/恢复、手动整理今日与逾期待办 | 不执行桌面 AI 自动化脚本，不保证后台常驻 |
| 课程表 | 多课表、周网格/今日、课程管理、单双周、自定义时间、学期/节次、JSON 与教务文本导入、JSON/ICS 导出、本周时间块联动 | 无教务网页自动登录/OCR；XLSX 先转 CSV；课程冲突会跳过并报告 |
| 网页收藏 | 收藏增删改查、备注、导入导出、复制链接 | 不自动抓取任意网站元信息，不保证任意网页内嵌 |
| RSS | 共用真实解析器、订阅管理、摘要/已读/星标、转任务、XML/JSON 导入、手动 HTTPS 刷新 | 需微信合法域名；不做后台轮询；全文通过原文链接阅读 |
| 数据中心 | 桌面封装备份/旧 JSON、预览确认、合并或替换、JSON 文件与剪贴板、任务 CSV 导入/导出、时间块 CSV 与 ICS 导出 | 尚无通用 ICS/XLSX 导入；大数据仍受微信总体配额约束 |
| 局域网 | 私有 IPv4 配对、电脑探测、拉取后预览、提交回传、查询接收状态 | 需同一可信 Wi-Fi/可用本地网络权限；HTTP 不加密；未做真实设备联通验收 |

尚未新增原生适配的两个内置插件是**学校通知网站、警大门户通知**。系统常驻、全局快捷键、悬浮窗、可靠后台响铃、原生 OCR、完整桌面 AI 自动执行和任意插件包执行也未伪装为可用。

## 使用入口

- **任务表顶部**：收件箱、课程表、插件中心。
- **任务长按**：上移/下移、移动象限、排入今天、删除等。
- **任务表批量操作**：勾选后完成、恢复、移动、删除；可撤销。
- **任务详情**：标签、自定义分钟、附件和排程日期。
- **课程表 → 导入**：选择 JSON/CSV/TSV/TXT/HTML 或粘贴，先解析预览，再新增课表或合并。
- **设置 → 数据**：文件备份、恢复、表格/日历导出。
- **设置 → 局域网**：先测试连接，再拉取预览或提交回传。电脑仍需自己确认接收。

## 数据兼容与保护

1. 与桌面共用 `tasks / blocks / settings / plugins / inbox / automation` 数据结构；额外字段保留。
2. 兼容 `le-time-backup` schema 2 封装及旧原始 JSON；拒绝重复 ID、不安全字段与不支持的未来 schema。
3. 合并保留本机重号记录及已有插件配置；替换恢复必须显式确认。
4. 主存储键迁移到 `letime-data`，旧 `tidebalance-data` 只读保留作为回退，不自动删除。
5. 较大快照先写分块、再提交清单；写入失败不把半份数据替换原快照。读取损坏/未来版本数据时保护原存档，不用空种子覆盖。
6. 显式备份恢复、课表导入、资料 JSON/RSS XML 导入须保存成功才切换数据或报告成功。
7. 退后台立即保存；批量修改合并刷新/写盘；图片预览临时文件在详情页卸载后清理。
8. 局域网回传复用原有电脑端开关、确认和恢复点；`pending` 不等于已接收，不添加绕过电脑确认的接口。

本次没有读取或迁移用户正在使用的真实微信存储；迁移逻辑会在小程序运行时执行，回归使用的是隔离 mock 数据。

## 代码组织

以下路径均相对仓库根目录：

- `miniprogram/core/storage.js`、`miniprogram/core/store.js`：存储提交、保护态、批量/排序/撤销与日期级排程。
- `miniprogram/core/transfer.js`、`miniprogram/core/files.js`：跨端备份、CSV/ICS、原生文件入口。
- `miniprogram/core/schedule.js`、`miniprogram/core/library.js`、`miniprogram/core/lanSync.js`：三个原生插件和局域网业务适配。
- `miniprogram/core/media.js`、`miniprogram/core/undo.js`、`miniprogram/core/pluginRoutes.js`：附件、跨页撤销及能力入口。
- `miniprogram/pages/schedule/`、`miniprogram/pages/library/`、`miniprogram/pages/inbox/`：新增页面。
- `tools/sync-miniprogram-models.js`：从桌面事实源生成课程模型/RSS 解析器及许可文件。
- `tools/build-schedule-plugin.js`：生成和检查流程同时覆盖小程序模型。
- `miniprogram/licenses/shiguang-schedule/`：保留上游许可证和归属说明。

Windows/Android 的业务界面不是本轮重写对象；共享侧变动集中在产品/插件版本、清单、生成校验与测试预期。保留了其他并行任务的修改，未 reset 或自动提交 Git。
