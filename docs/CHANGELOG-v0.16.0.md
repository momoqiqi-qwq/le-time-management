# Le时间管理 v0.16.0

## 改了什么

学习通插件（`chaoxing-notify`）升到 **2.3.0**，课程页从「一屏平铺」改成**按年级分组**，
并给每门课加上完成状态标记。

### 课程页：年级自动分组

课程列表按**大一 / 大二 / 大三 / 大四 …** 分组展示，每组标题带一行概览
（如「2025-2026 学年 · 共 8 门 · 已完成 3 · 未完成 5」）。

年级是**本地推断**出来的 —— 学习通课程接口只返回 `courseId / clazzId / 课程名 / 教师 / 班级`，
既不给年级也不给完成状态。插件用的是课程卡片里唯一的时间信号
「开课时间：YYYY-MM-DD～YYYY-MM-DD」：

- 开课月份 ≥ 7 判为秋季学期（学年 = 当年），否则春季学期（学年 = 上一年）；
- 年级 = 开课学年 − 入学学年 + 1；
- 入学学年靠**投票**确定：班级名里的「25防火」「25英普」这类前缀、以及文本里的「20XX 级」
  各投一票取众数；都没票时退回最早的开课学年。

没有开课时间的课程会被归到最后一组「其他（无开课时间）」。

> 注意：结课时间一律等于开课时间 +2 年，不能拿来判断是否完成，所以代码里明确只读开课时间。

### 课程卡片：已完成 / 未完成标记

- **已完成**（灰标）：开课学期早于当前学期 —— 卡片整体也转为浅灰底。
- **未完成**（黑标）：开课学期为当前学期或更晚。
- 无法判断时**不显示标记**，而不是硬塞一个状态。

页脚常驻一行说明，明确写出这两项都是本地推断、学习通接口并不返回，
**可能有平台显示不一致**，不假装成平台原始数据。

### 其他

- 课程页新增入学年份提示：识别到时会写「按 2025 级入学计算」，识别不到则只按学年分组。
- 课程卡片在年级分组内保持接口返回的原始顺序，不做二次排序。
- 用真实账号的 57 门课实测：大一（2025-2026 学年）32 门全灰标、大二（2026-2027 学年）
  15 门全黑标、10 门社团/培训课（卡片无开课时间）归「其他」——与实际学期完全吻合。

## 影响范围

- Windows / Android 共用前端与同一份插件源码，两端同时生效。
- 微信小程序：该插件在小程序侧为 `unavailable`，只同步应用版本号。
- 本次只改插件 JS 与清单，无需重新构建 Rust 侧的额外依赖。

## 数据迁移

无需迁移。本次改动全部是课程页的展示层逻辑，不新增也不修改任何存储字段；
已有任务、时间块、提醒与插件收藏保持不变。

## 测试

`scripts/test-chaoxing.mjs` 扩充课程页用例：`termOf` / `currentTerm` 学期换算、
`gradeOf` 年级递推（含「入学前」与认不出入学年份时不硬造年级）、
`detectEnrollYear` 从「25防火」「25英普」投票推出入学年份、
`courseStatus` 已完成 / 未完成判定、`courseGroups` 分组与排序。

测试脚本 13 个，全部通过。
