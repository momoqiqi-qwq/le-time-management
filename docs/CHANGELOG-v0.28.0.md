# Le时间管理 v0.28.0

## 改了什么

- 时光课程表新增“中国人民警察大学”本科教务适配器。
- 完成统一身份认证后，适配器会自动打开“课表明细”，不需要用户在多层菜单中寻找。
- 按警大实际 JE/ExtJS 教务接口加载完整学期，不只导入列表当前页的 30 条记录。
- 将每次上课日期按课程、教师、地点、节次和星期合并为课程周次，并自动设置学期开始日。
- 警大适配器随应用离线内置；旧版已有本地学校仓库的用户升级后也会自动补入，不依赖 GitHub 下载。

## 影响范围

- Windows 原生时光课程表。
- Android / Web 内嵌课程表。
- 课程表插件版本升至 `3.2.0`。

## 数据迁移

无破坏性迁移。旧课表数据保持不变；新适配器只在用户主动确认导入时写入选中的课表。
