# 时光课程表界面适配说明

本次修改遵循“保留课程表原功能与原版周课表结构，只改界面并优化打开速度”的要求。

## 保留内容

- 手动添加、编辑、删除课程
- 学期日期、总周数、周一/周日起始设置
- 节次时间表
- 今日课表 / 周课表切换
- 教务 CSV / TSV / TXT / HTML 导入与预览
- JSON 备份导入 / 导出
- ICS 导出
- 课程冲突检测
- 加入 Le 时间块以及重复/冲突保护
- 原有数据模型和存储键，不迁移、不清空已有课程数据

## 界面调整

- 周课表恢复为时光课程表原版思路：左侧节次与上下课时间、顶部星期和日期、课程块按节次跨行显示。
- 小屏不再改成“每天一张卡片”，而是保留原课表结构并允许横向滑动。
- 颜色、圆角、边框、深色模式跟随 Le 时间管理主题变量。
- 今日课表、编辑、设置、导入、备份页面仍使用 Le 的表单与卡片风格。

## 打开速度优化

- 课程表首次读取并标准化后保留在插件内存中；在应用本次运行期间再次打开时，不重复读取存储和标准化整张课程表。
- 按“课表对象 + 周次”缓存当周课程 occurrence 与冲突计算，切换视图或执行时间块联动时复用结果。
- 周课表渲染时复用节次索引，不再为每门课程重复建立节次映射。
- CSS 仍只注入一次。

## 验证

已运行 `01-windows/scripts/test-schedule.mjs`，原有 JSON 往返、周次、节次/自定义时间、冲突、ICS、时间块幂等、教务导入与合并测试全部通过。
