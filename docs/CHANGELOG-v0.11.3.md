# Le时间管理 v0.11.3

## 设置中心 UX
- 设置页新增顶部搜索，可按“背景 / 快捷键 / WebDAV / 提醒”等关键词直接定位。
- 新增分类筛选：外观、提醒、数据/同步、操作、插件、关于；移动端分类横向滚动。
- 设置导航保持吸顶，长设置页不再需要反复上下滚动找入口。

## 更多界面自由度
- 新增“界面与交互”设置：舒适 / 紧凑密度、90%～120% 文字大小、跟随系统 / 完整 / 减少动效。
- 可单独关闭顶部任务统计、页面副标题和触摸左右滑动翻页。
- 可设置启动后继续上次页面，或固定进入四象限 / 时间块 / 收件箱 / 插件中心。
- 新增舒适、高密度、低干扰三套一键预设，并支持恢复界面默认。

## 代码结构
- 新增 `src/uiPreferences.js`，集中处理 UI 偏好的默认值、归一化、应用与持久化。
- 将设置页的外观/背景逻辑拆到 `src/views/settings/appearance.js`。
- 将插件管理拆到 `src/views/settings/plugins.js`。
- 将设置搜索/分类导航拆到 `src/views/settings/navigator.js`。
- `settings.js` 从 650+ 行降到约 330 行，后续继续加设置时更容易维护。
- `store.js` 增加统一 `normalizeState()`，对损坏/旧格式顶层字段做更稳健的兼容归一化。

## 兼容性
- 新设置保存在现有 `settings.ui` 下，不改变任务、时间块、插件数据结构。
- Windows 与 Android 共用同一前端，因此界面偏好与设置中心同步生效。
- 微信小程序会保留备份中的 `settings.ui` 字段，但本版本暂不应用桌面端界面偏好。
