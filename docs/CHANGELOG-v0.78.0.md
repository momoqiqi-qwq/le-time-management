# v0.78.0

## 新增

- 全局搜索新增设置项级索引，覆盖界面、主题、提醒、数据、同步、AI、快捷键、局域网、插件与关于设置；点击结果会打开对应分区、滚动到具体选项并短暂标出落点。
- 桌面侧栏插件改为实时拖拽排序：拖动项浮起、原位保留明确空槽，其他插件逐项平滑追赶；指针停下时布局保持当前状态。
- 侧栏插件支持 `Alt+↑/↓` 键盘排序，并尊重系统或应用内的“减少动效”设置。

## 影响范围

- Windows 桌面端：全局搜索与插件侧栏。
- Android：全局搜索设置直达；移动端插件入口仍集中在插件页，不显示桌面侧栏拖拽。
- 无数据迁移；插件顺序继续保存于现有 `settings.pluginOrder`。
