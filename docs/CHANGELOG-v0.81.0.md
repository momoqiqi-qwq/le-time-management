# v0.81.0

## 界面与交互

- 左下角“缩放视图”的收缩/展开图标在深色模式下显示为白色，覆盖普通、激活和拖拽状态。
- 右上角工具区新增设置按钮，打开原有设置面板；保留用户的顶栏顺序，新入口自动补到窗口控制之前。
- 顶栏与左下快捷操作条使用同一套指针拖拽：跟手浮起、占位、其他按钮平滑让位、松手落位。
- 键盘 Alt+左/右也播放换位动画；保留触屏长按、取消回滚和拖动结束防误点击，兼容界面缩放与减少动效偏好。

## 影响范围

- 主应用工具栏、深色图标与拖拽反馈；不改变现有设置内容、插件行为或窗口控制功能。
- 没有数据结构迁移，不重置用户任务、偏好和已保存的按钮顺序。
- 三端版本按仓库约定同步；微信小程序未添加上述桌面工具栏功能。

## 回归覆盖

- 新增工具栏交互用例：存档兼容、实时换位、落位、取消、长按、键盘、减少动效与缩放坐标。
- 既有操作条守卫随共享模块提取更新检查位置，原有行为要求保持。
- Android 布局守卫调整为全平台禁用 HTML5 原生拖拽，并确认共享指针拖拽已接入；桌面窗口控件的平台门控保持。
