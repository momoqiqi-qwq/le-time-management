# CHANGELOG v0.11.5

发布日期：2026-09-11

## 本次调整

### 1. 设置页改为分类导航布局
- 将原本纵向堆叠的设置页整理为“左侧分类 + 右侧内容”结构。
- 新增设置页头部说明区与分类标签。
- 保留搜索能力，支持按分类快速定位。

### 2. 新增右上角可拖动快捷功能盒
- 新增仿参考图风格的浮动“快捷入口”功能盒。
- 支持拖动位置，并自动持久化。
- 内置快速新建、命令搜索、四象限、时间块、收件箱、插件中心、设置、窗口置顶、最小化、关闭。
- 按用户要求，未加入多账户入口。

### 3. 顶栏主题融合优化
- 将标题区域做成主题卡片式样，提升一体感。
- 右侧操作按钮改为卡片分组样式，更贴近参考图三。
- 整体阴影、圆角与层次感同步调整。

## 影响范围
- Windows / Tauri 前端界面
- 设置页布局
- 顶栏视觉
- 快捷操作入口

## 备注
- 本次主要为 UI / UX 微调，不涉及数据结构破坏性变更。
