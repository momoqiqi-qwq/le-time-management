# v0.11.4 定向优化说明

本次按三个 UI/UX 要求处理：

1. **删除逐项权限管理**
   - 插件中心移除「权限 / 管理」按钮。
   - 设置 → 插件移除权限 chip、逐项勾选和运行时权限计数。
   - 插件只保留总开关，使用滑块开启 / 关闭；「打开」按钮只负责进入插件视图。
   - `manifest.permissions` 仍作为插件能力声明与宿主 API 边界，避免插件调用未声明能力；不再提供用户逐项授权状态。

2. **主 UI 使用 Icons8 / iGoutu iOS Filled 图标**
   - 主导航、插件中心、插件管理的 `appIcon()` 已切换到 iOS Filled 风格。
   - 图标由 Icons8 官方图片 CDN 加载，并在“关于 / 开源说明”加入来源与署名说明。
   - 网页收集插件和微信小程序的既有 Font Awesome 资源暂时保留，避免一次性影响其站点图标推断与小程序离线生成流程。

3. **通知正文展开 / 收起动画**
   - 警大门户通知由“点击后整列表重绘”改为“当前卡片原位状态切换”。
   - 使用 `grid-template-rows: 0fr → 1fr`、opacity、translate、箭头旋转组合动画。
   - 异步正文加载完成后只更新当前卡片详情，不再重绘整列表，减少滚动位置跳动。
   - 支持 `prefers-reduced-motion`，系统要求减少动画时自动缩短过渡。
