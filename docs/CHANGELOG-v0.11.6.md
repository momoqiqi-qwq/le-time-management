# CHANGELOG v0.11.6

发布日期：2026-09-11

## 1. 删除照护类遗留功能
- 移除“长辈照护 / 安心日常”相关遗留主题和样式。
- 删除老人大字主题入口及对应配色、旧 care / elder CSS。

## 2. 直接跳转动画
- 主视图切换增加退出淡化 + 原有入场滑动的组合动画。
- 命令面板、插件直达、快捷功能盒等直接跳转统一复用。
- 设置分类定位增加平滑滚动与短暂高亮。
- 遵循“减少动态效果”设置。

## 3. AI 配置与加密凭据
- 设置中心新增“AI 与自动任务”。
- 支持 OpenAI 兼容 Base URL、模型、API Key。
- Base URL / 模型 / API Key 不写入 data.json；Rust 后端使用 AES-256-GCM 加密保存到独立 vault。
- API Key 在界面只显示掩码，留空保存时保留已有 Key。

## 4. AI 自动任务
- 支持创建多个规则。
- 支持每天、指定星期、每周一次、仅一次。
- 支持自然语言生成规则，例如“每晚 22:30 整理未完成任务”。
- 到点后调用 AI，根据应用内任务、时间块、收件箱摘要返回白名单操作。
- 失败后 10 分钟重试；应用启动时会补跑已到点但未执行的规则。
- 手动“立即执行”不会消耗当天的正式定时执行。

## 5. AI 权限边界
AI 自动任务只允许：
- 创建任务
- 更新任务
- 创建时间块
- 添加收件箱事项

明确不提供：
- 读取本地文件
- 写入 / 删除本地文件
- 执行 shell / 系统命令
- 打开任意本地路径
- 调用插件文件读写接口

## 验证
- Windows 端全部 Node 行为测试通过。
- 新增 v0.11.6 AI / 多规则 / 本地文件边界 / 动画静态回归测试。
- 当前容器没有 Rust 工具链，Rust 代码未在本环境执行 cargo check；建议本机最终执行 `npm install && npm run tauri build`。
