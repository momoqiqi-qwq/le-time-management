# v0.36.3 变更日志

主题：**手机端继续瘦身 + 课程表观感**。三处都来自用户真机反馈（Android 截图）。

## 1. 顶栏并成一行（Android 每页省一整行）

`@media(max-width:760px)` 里顶栏原来是 `flex-wrap:wrap` + 标题卡/工具卡各占 `width:100%`，
导致「标题卡一行 + 搜索胶囊一行」两行起手。现在：

- `flex-wrap:nowrap`、高度固定 `calc(54px + safe-area)`，标题卡 `flex:1 + min-width:0`，
  工具卡 `flex:none` 靠右；
- `.topbar-title-copy .sub` 加 `nowrap + ellipsis`（插件副标题改成长描述后必须截断，见下）；
- `@media(max-width:560px)` 的 `.topbar-action-card` 从 `flex-wrap:wrap` 改 `nowrap`
  （否则嵌套换行又把行撑高）。

## 2. 插件页副标题不再显示裸插件 ID

`shell.js` 的 `viewDef()` 原来 `sub: v.pluginId`，手机上课程表页顶栏显示「shiguang-schedule」，
占位且无信息量。改为读注册表里的 **manifest.description**（找不到再回退插件 ID）。

## 3. 插件市场头部瘦身（搜索收成图标）

用户反馈：搜索框独占一行 + 一段长说明，占位太多。改动：

- 删掉「支持按名称、ID、功能和作者搜索；插件开启 / 关闭统一使用滑块开关。」整行说明
  （与输入框 placeholder 重复）；
- 统计并入头部一行（`market-head` 不再 `flex-direction:column`）；
- **≤700px 搜索默认收起**，头部右侧一个 `⌕` 图标按钮（`.market-search-toggle`），点击展开
  输入框并自动聚焦；展开状态存模块级 `marketSearchOpen`，切页不丢。桌面端不受影响
  （图标与收起逻辑都只在 ≤700px 生效）。

## 4. 课程表页头去重（「第 N 周」只出现一次）

原布局是 `screenHead('第 N 周', …)` 大标题一行 + 下面 `.schedule-top` 卡片里又来一个
「第 N 周 / 点击快速跳转」，同一屏「第 1 周」出现两次。现在合并成**一行 sticky 头**：

```
‹   第 1 周（大标题，点击快速跳转）        ›   切换课表
        我的课表 · 共 20 周 · 点标题快速跳转
```

- `.week-title` 从居中纯文字改成左对齐「大标题 + 副行」，本身仍是 `week-picker` 触发按钮；
- 删除 `.week-nav` 三列网格及其 620px 窄屏规则；
- 顺带 `@media(max-width:620px)` 里 `.week-title b` 收到 18px。

## 5. 彩色调色板换成 WakeUp 风格彩虹（仍过 WCAG AA）

用户给了 WakeUp 课程表截图，希望彩虹感更强。8 档实色全部重挑：**每个色相取「白字压上面
≥4.5:1 的最浅色」**（按 HSL 扫描，饱和度限制在协调区间 54–74%）：

| 档 | 旧 | 新 | 白字对比度 |
|---|---|---|---|
| 0 蓝 | #2563eb | **#3174D9** | 4.53 |
| 1 薄荷绿 | #0f766e | **#25855D** | 4.57 |
| 2 橙 | #b45309 | **#AD6323** | 4.58 |
| 3 淡紫 | #7c3aed | **#9A54D8** | 4.53 |
| 4 珊瑚红 | #c0392b | **#CB4C33** | 4.54 |
| 5 青 | #0e7490 | **#278092** | 4.58 |
| 6 绿 | #15803d | **#288738** | 4.55 |
| 7 玫红 | #4338ca | **#D23F64** | 4.53 |

`--course-on` 仍是 `#fff`；调色板依旧**刻意不跟随主题**（白色文字的硬门槛决定的，实色底不能跟着
深色模式提亮）。若真要做到参考图那种更浅的粉彩，白字只有 2.6~4.2:1，会掉出 WCAG AA——
这是「白字 + 浅彩」的物理极限，不是实现偷懒。`test-schedule.mjs` 的逐档 4.5:1 断言原样通过。
