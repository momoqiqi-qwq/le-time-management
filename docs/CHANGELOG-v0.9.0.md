# Le时间管理 v0.9.0

## 界面重构

本版以用户提供的 `tauri-app-template-main` 为视觉参考，在不引入 React/Tailwind 重写成本的前提下，将其设计语言迁移到现有原生 JS/Tauri 界面。

- 统一中性背景、卡片表面、细边框、低阴影、紧凑按钮和输入框。
- 桌面侧栏改为主题化浅表面卡片，活动项用低饱和强调色表达，不再依赖大面积深色背景。
- 主工作区桌面端增加独立容器边界，顶部标题栏改为轻量半透明表面。
- 四象限、时间块、插件市场、设置页、任务卡、抽屉、弹出菜单和 Toast 统一圆角与交互状态。
- 插件市场卡片改为左对齐信息结构，提升名称、说明和“进入”动作的阅读顺序。
- Focus ring、滚动条、hover/active 状态统一，改善键盘与鼠标交互反馈。
- 900px 以下继续使用移动底栏，同时同步新的中性卡片风格。
- 微信小程序同步调整 card / button / input / plugin / settings 样式，保持跨端视觉一致。

## 兼容性

- 保留现有 9 套主题与主题变量；新版 UI 通过 `color-mix()` 从当前主题色派生边框、强调和焦点色。
- 不改变任务、课程表、通知、PushPlus、插件数据格式。
- Windows 测试全部通过；微信小程序核心测试 46/46 通过，静态检查通过。
