# Le时间管理 v0.27.0

## 改了什么

### 考试日历：列表重排 + 修掉 3 个会显示错误信息的问题

**修 bug**

- **多日考试进行中时倒计时变成「N 天前」**（小程序更糟，会显示「-1 天后」）。
  列表过滤用 `endDate || date` 判断「还没结束」，倒计时却用 `date` 算差值 —— NCRE 这类
  连考 3 天的场次从第 2 天起 `date` 已经过去，仍会列出但倒计时为负。
  现在按 `endDate` 判定，显示「进行中 · 第 2 天」（蓝色高亮）。数据集里 4 个跨日场次
  （2026-09-19~21、2026-12-05~06、2027-03-27~29、2027-09-18~20）都会踩到。
- **「排进日程」只排第一天**。跨日考试原先只用 `ev.date` 建一个时间块，第 2、3 天在日程里
  凭空消失；现在整个区间逐日建块，任务截止日取最后一天。桌面端与小程序端一致。
- **时长口径不一致**：任务 `estMin` 用 150（笔试）/60，时间块 `durMin` 却默认 120。
  现在两端统一走同一个函数：有起止时间就用实际时长，否则按类型给默认值。
- **主程序自动化读到的是空数据**。`src/automation.js` 的 `examReminderFromStorage()` 读
  `plugins["exam-calendar"].storage.events`，但插件从不写这个键，这段逻辑永远扫到 0 条。
  现在插件在 `tick()`（加载时 + 每 10 分钟）把未来场次快照落盘，自动化与其它视图可读。
- 提醒补上「跨日考试最后一天」：原先只在考前 7/3/1/0 天推，连考第 2、3 天整段静默。

**列表重排**

- 日期列固定 112px（原先 `min-width:132px`，区间行实际约 200px，导致考试名起始位置参差）。
  行内改为三列 grid：日期列 / 名称+元信息 / 操作列。
- 日期写法改为 `09-19 → 09-21` + `周六 → 周一`：去掉与年份分组标题重复的 4 位年份，
  补上结束日星期。旧写法「2026-09-19 周六~09-21」会被读成「周六 ~ 09-21」。
- 徽章分级：可信度改成彩色圆点（实心＝官方已确认，空心＝规则推算）并带 tooltip；
  类型（口试/面试/准考证打印）改为中性灰底标签；时间并入元信息行，不再和状态混用同一种胶囊。
- 倒计时分档着色：进行中（蓝）/ ≤3 天（红）/ ≤14 天（橙）/ ≤60 天（常规）/
  更远改显示「约 N 个月后」或绝对日期。原先 2027 年的场次显示「453 天后」毫无行动指导意义。
  3 天内与进行中的行左侧加红色竖条。
- 操作收敛：每行从 2 个按钮降到 1 个主操作 + 1 个「公告」。原先的「看全流程」按钮
  实质是切全局筛选，14 行就是 14 个按钮且没有明显出口 —— 改为点击考试名进入，
  再点一次回到全部，全流程面板里也加了「回到全部考试」。
- 同年同日多条（2026-12-12 / 2027-06-12 / 2027-12-11 的 CET4+CET6）共用日期单元格，
  第二条显示「同日」并拼接边框，不再整列重复日期。
- 年份分组标题补场次数；整组都是「预计」时标注「规则推算，仅供参考」，行改虚线边框并降透明度。
- 筛选从下拉框改为 chips（全部 / CET4 / CET6 / NCRE / 教资 / 考研 / 专四 / 专八）+「只看官方」。
- 新增搜索框（按名称 / 分类 / 类型过滤，只切显隐不重建 DOM，不会丢焦点）。
- 新增底部「历史场次」折叠区：77 条数据里已结束的 63 场原先完全没有入口。
- 「排进日程」按钮改为有状态：已排过的显示「已在日程」并禁用，重建视图后仍能恢复。
- 数据陈旧提示阈值 90 天 → 30 天。原先采集于 2026-09-10 的数据要等到 2026-12-09 才提示，
  而 12-12 的 CET 就在那前后。

**小程序端同步**

- `futureExams()` 修掉「-1 天后」，输出结构与桌面端对齐（`dateTop` / `dateBottom` /
  `metaText` / `countdown` / `tone` / `hot`），可信度文案统一为「官方已确认 / 规则推算」。
- 新增 `pastExamGroups()`，列表按年倒序分组。
- 页面新增搜索、只看官方、历史场次折叠；`onAddExam` 支持跨日区间与「已在日程」状态。
- 同日多条排序与桌面端对齐（只按日期排，保留数据原始顺序，不再按名称二次排序）。

## 影响范围

- 桌面端插件 `public/plugins/exam-calendar/main.js`（插件版本 0.2.1 未变，属实现改动）。
- 小程序 `core/pluginRuntime.js`、`pages/plugin/index.{js,wxml,wxss}`。
- 主程序 `src/automation.js` 依赖的 `storage.events` 现在有数据了（该文件本身未改）。
- 插件清单与 `pluginCatalog` 未变（`manifest.json` 未动）。

## 数据迁移

无。插件新增的 `storage.events` 是只读快照，缺失时下次 `tick()` 自动重建；
`settings` 与 `reminded` 结构未变，旧的本地数据可直接沿用。
