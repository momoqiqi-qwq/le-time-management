# v0.93.4

## 更新内容

- 学习通待办作业新增「一键移除逾期」按钮，可把当前已逾期未提交作业批量从本机列表隐藏；不影响学习通平台数据，可通过「恢复已移除」放回。
- 警大请假视图支持在课次卡片上直接发起请假草稿：选择课次、填写理由后可打开教务提交，也可先保存为 U-Time 待办。
- 警大创新学分汇总卡新增「展开看看是什么项目」，展示教务接口返回的可用项目字段；若接口只有汇总字段，会提示去教务查看完整明细。
- 侧栏插件视图列表增加「上下拖动排序」提示，保留拖动后持久化排序能力。

## 影响范围

- Windows / Android 桌面与移动端内置插件清单同步更新。
- 小程序同步插件清单与版本元信息。
- 无数据迁移。
