# Le时间管理 v0.4.0

## 新增

- **网页收集插件** (`web-collector`)
  - 输入 URL 自动补全 `https://` 并规范化地址。
  - 读取 `og:site_name` / `application-name` / `<title>` 获取网站名称。
  - 读取 `rel=icon` / `apple-touch-icon` 获取 favicon；失败时回退 `/favicon.ico`。
  - 根据站点名称和域名推断 Font Awesome 图标名（学校、图书馆、新闻、代码、视频、音乐、邮箱、云盘、购物、地图、论坛、文档、日历等）。
  - 收藏支持搜索、备注、重命名、刷新元信息和删除。

- **学校通知网站插件** (`school-notice`)
  - 输入学校通知/公告网址后自动提取公告标题、日期、链接和摘要。
  - 识别常见高校 VSB / VisualSiteBuilder、WordPress、Drupal、DedeCMS、SiteEngine，以及通用公告列表。
  - 支持单独配置登录网址；使用 Rust Cookie Jar 保持当前会话。
  - 自动识别登录表单 action/method、账号字段、密码字段、隐藏字段和常见验证码字段。
  - 图片验证码通过同一登录会话读取并显示，由用户手动输入；**不绕过验证码**。
  - 密码不写入本地存储；动态 JS 加密、扫码、短信、OAuth/复杂统一认证会提示需要专用适配器。
  - 公告可一键打开，也可尝试识别时间后转为 Le时间管理任务/时间块。

- **主题**
  - 新增：深海蓝、樱花粉、松林绿、暮光紫、极简灰。
  - 总计 9 套主题；侧栏和课程表进一步改用全局主题变量。

## 性能与代码优化

- 新增 `src/webContent.js`，网页 URL、站点元信息、favicon、图标推断、公告列表、登录表单和表单编码集中复用，避免两个新插件各写一套解析代码。
- 插件宿主改为**清单/入口并行读取、按清单顺序注册**，缩短插件可用等待时间并保持侧栏顺序稳定。
- `tide.http.getCached(url, ttlMs)` 增加进程内短期缓存，避免短时间重复抓取同一公开页面。
- 中国节假日首屏改为缓存/内置数据并行读取；不会为了下一年尚未公布的数据触发一次慢公网请求；只有当前查询年份缺失才按需联网。
- 课程表：
  - 日期解析缓存；
  - 节次编号 `Set` 校验；
  - `WeakMap` 缓存节次查找表；
  - 已是数组的周次走快速校验路径；
  - 每周日期一次生成；
  - 周视图一次按天分组；
  - “今天”冲突只计算一次。
- 小程序插件图标生成工具改为直接读取桌面端 manifest，新增插件无需手工维护第二份 `plugin_icons` 映射。

## 平台

- Windows / Android：12 个内置插件同源运行。
- 微信小程序：同步显示 12 个插件及启停状态；继续保留 5 个原生适配插件。网页收集、学校通知网站因网络/Cookie/DOM 运行时限制暂标记不可用。
