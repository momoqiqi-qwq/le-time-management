# v0.95.0

## 更新内容

- 警大门户通知支持详情附件显示：正文为空但内容在附件里的通知，展开后会显示附件列表。
- 警大门户通知支持附件下载：优先使用当前门户会话在应用内下载，失败时自动打开原附件链接兜底。
- 警大门户通知新增「考试 / 比赛 / 通知」分类筛选，并在通知卡片上显示分类标签。
- 网址收藏（web-collector v1.4.0）支持拖入即收藏：把浏览器标签或页面上的链接直接拖进插件页即可自动读取名称、favicon 与图标，一次最多 12 个；落区只描虚线框提示，带文件（如截图）的拖放仍交给全局快速捕获，不在此拦截。

## 影响范围

- Windows / Android：警大门户通知插件、网址收藏插件。
- 小程序：同步插件目录信息，不开放这两个插件运行。

## 数据迁移

- 无数据结构迁移。
