# Le时间管理 v0.11.0

主题：数据中心与自动化。

## P0

- 新增「数据中心」：完整 JSON 备份/恢复、任务/时间块 CSV、Excel `.xlsx`、iCalendar `.ics` 导入导出。
- 导入前自动创建恢复点；支持每天/每周自动备份与保留数量设置。
- 新增自动化规则引擎：截止任务自动排程、考试节点、课程同步、每日整理。
- 新增统一「收件箱」页面，集中承接插件与自动化产生的待确认事项。
- 新增自动化操作日志；会改变任务/时间块的自动操作保存前态，支持一键撤销。
- 截止日期进入 14 天内、且尚未安排的任务可自动寻找截止日前空闲时段。

## P1

- 警大门户通知拉取后自动进入收件箱，默认不直接创建任务，避免误识别造成污染。
- 考试日历提醒同步进入收件箱，可一键创建任务。
- 课程表自动同步规则可选开启：按当前教学周生成学习时间块，跳过重复课程。
- 课程与任务时间冲突时，自动重排仅移动「由任务产生」的可移动时间块；手工块/课程视为固定事件，无法安全处理时进入收件箱。
- 每日整理会把逾期未完成任务的截止日调整到今天，并留下可撤销日志。

## 安全与兼容

- 普通备份不额外收集或导出密码、WebDAV 密码、登录 Cookie。
- Excel 支持由 `xlsx`（SheetJS Community Edition）提供，已加入 npm 依赖。
- Windows 与 Android 共用前端实现；微信小程序继续保持 v0.11.0 数据结构兼容，但本次新的桌面数据中心 UI 不移植到小程序。
