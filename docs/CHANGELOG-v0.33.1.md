# Le时间管理 v0.33.1

## 修复内容

- 修复 Android 四象限页面沿用桌面剩余高度布局后，四张卡片被压缩、任务与“添加”按钮被裁剪，触摸实际命中错误容器而表现为无响应的问题。
- Android 四象限改为内容自然增高，由页面统一纵向滚动；卡片宽度限制在屏幕内，避免窄屏横向溢出。
- Android 不再创建桌面专用的最小化、最大化、关闭、窗口置顶和启动窗口大小控件。
- Android 顶栏和隐藏的插件直达项不再启用 HTML5 拖拽，避免拖拽手势与触摸点击竞争。
- 新增 Android 布局回归测试，守住自然高度、按钮不裁剪和桌面控件隔离。

## 影响范围

- Android：修复。
- Windows：桌面窗口控制与顶栏拖拽行为保持不变。
- 小程序：仅同步版本号，无功能改动。

## 数据迁移

无。现有任务、时间块、插件与设置数据无需迁移。
