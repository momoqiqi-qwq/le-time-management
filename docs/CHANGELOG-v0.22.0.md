# Le时间管理 v0.22.0

## 改了什么

- 警大门户插件升级至 1.4.0：应用重启后会从加密 Cookie 中恢复门户 `tp_up`，优先复用仍有效的门户会话。
- 补全主 SSO → `sso-jw` bridge → 门户的静默续期链路；短票据过期但主 SSO 仍有效时，无需重新输入验证码。
- 保留原有的加密密码、验证码自动识别和最多 6 次换图重试兜底。
- 新增“自动刷新”开关：打开插件期间每 10 分钟同步一次通知，离开插件后自动停止，避免后台空耗。
- 修复内置插件入口被 WebView 强缓存的问题；升级后会按插件版本拉取新代码，老用户不再继续运行旧版警大插件。

## 影响范围

- Windows：完整支持。
- Android：与桌面端共用插件代码，完整支持。
- 微信小程序：警大门户插件仍不可用。

## 数据迁移

- 无需迁移。已有的加密密码与 Cookie 数据可直接继续使用。
