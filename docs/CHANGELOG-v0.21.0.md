# Le时间管理 v0.21.0

## 改了什么

新增 **5 套主题**（界面主题总数达 16 套），每一套都锚定一个真实的材质世界，
而不是泛泛的「好看颜色」。全部为浅色主题（深色模式仍统一走「夜间护眼」），
变量覆盖完整度与既有主题一致（`styles.css` 结构校验通过，26 个变量全覆盖）。

| 主题 | 出处 / 签名 | 主操作色 | 点缀 |
|---|---|---|---|
| **青瓷釉色** `celadon` | 南宋龙泉窑粉青釉，雾青灰绿纸面 | 釉青 `#3D6B5B` | 釉里红 `#C96A5E`、窑金 |
| **敦煌暮色** `dunhuang` | 莫高窟矿物颜料：沙金泥面 | 石青 `#2F5D68` | 朱砂 `#C0452E`、金箔 `#D19A2B` |
| **晒图蓝** `blueprint` | 蓝晒制图纸，圆角收紧到 8px 显制图感 | 普鲁士蓝 `#1D4E89` | 安全橙 `#E15A33` |
| **蜜柑汽水** `citrus` | 夏日橘子汽水，奶油底、14px 大圆角 | 蜜柑橙 `#CE5F05` | 汽水蓝 `#2B8AC4`、葡萄紫 |
| **极光晨雾** `frost` | 极地雪原（Nord 系），雪暴灰底 | 冻雾蓝 `#5E81AC` | 极光绿 `#8FBC72` |

设计约束：五套主色互不撞车、与既有 11 套气质错开（claude 已是暖纸+陶土橙、
mono 已是灰阶，均不复用）；侧栏 `--deep-2` 全部压暗，保证侧栏浅色文字可读；
四象限色与主题主色同源推导，品牌四色徽标在各主题下保持协调。

## 影响范围

- 桌面端与 Android 端主程序界面（`src/themeProfiles.js` + `src/styles.css`）。
- 设置 → 界面 主题卡片自动渲染，无需额外 UI 代码。
- 小程序端不受影响。

## 数据迁移

无。主题 id 存于 settings.theme，老用户保持原主题不变。

## 测试

- `scripts/test-themes.mjs` 增加五个新主题的元数据断言。
- CSS 结构校验：花括号平衡、五个新主题 26 个变量全覆盖。
- `npm test` 15 个脚本全过；`sync-version.js --check` 三端一致 v0.21.0。
