# v0.89.0

## 新增

- 设置中新增“关键词标注”分区，可统一开关标注功能。
- 日期和时间默认以红色字体显示，支持自定义时间颜色。
- 支持最多 20 条自定义关键词规则，每条可单独选择颜色、字体着色或背景标注，并可独立启停。
- 任务表、收件箱和时间线中的标题、备注及时间信息会实时应用标注规则。
- 设置页提供实时效果预览，并支持一键恢复默认配置。

## 安全与兼容

- 标注内容通过文本节点分段渲染，不使用 `innerHTML`，避免关键词内容被解释为 HTML。
- 关键词配置随现有设置数据保存与同步，无需数据迁移；旧数据首次使用时自动采用默认时间标红规则。
- 适配桌面与窄屏布局，并沿用现有主题、字号缩放和深色模式配色体系。
