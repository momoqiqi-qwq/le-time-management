# v0.92.2

## 警大教育邮箱自动登录成功判定

- 优化「警大门户通知」校园服务栏里的教育邮箱入口：邮箱登录提交后不再只看 HTTP 成功或普通首页地址，而是必须识别到 Coremail 的 `sid` 会话入口。
- 打开浏览器前会用同一个插件 HTTP 会话二次访问该 `sid` 入口，确认没有回到登录页，避免“提示成功但浏览器仍未登录”的假成功。
- 如果邮箱站点返回账号/密码/验证码等登录失败文案，插件会直接提示失败并回退普通打开；不会把密码写进 URL、data URL、普通 storage 或同步备份。

## 影响范围与限制

- 修改 `public/plugins/cppu-notify/main.js` 与插件清单，影响 Windows / Android 共用前端的「警大门户通知」校园服务栏教育邮箱入口。
- 插件版本升到 `1.13.0`；应用版本升到 `0.92.2`。
- 无数据迁移。
