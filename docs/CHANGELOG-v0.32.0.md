# Le时间管理 v0.32.0

## 改了什么

### 一、番茄专注：到点提醒可配置，提示音可选可自定义

需求（用户反馈）：**「番茄专注时间可以设置提醒，提醒时可以设置声音，可自定义声音」**

原来番茄专注跑完只弹一条 toast，**没有任何声音**，也没有任何可配的地方。现在展开卡片底部的「提醒设置」：

| 设置项 | 说明 |
|---|---|
| 专注结束 | 「通知」「声音」两个独立开关 |
| 休息结束 | 同上，与专注互不影响 |
| 提示音 | 7 种内置音效（清脆提示 / 三音铃 / 钟声 / 木琴 / 电子哔 / 急促三连 / 柔和低音）+「自定义音频」 |
| 音量 | 0～100% 滑杆 |
| 自定义音频 | 导入本地音频（≤ 4 MB）、清除、随时试听 |

- 折叠标题栏上有一行速览：`专注 开 · 休息 开 · 三音铃 60%`，收起时也能一眼看到当前配置。
- 换提示音、拖动音量、导入音频都会**自动试听**一次，不用来回点。
- 设置存在插件的 `reminder` 键里；配置损坏会自愈 —— 比如选了「自定义音频」但音频丢了，会自动退回默认音，**不会到点一声不响**。
- 关联了任务时，完成后的「下一个番茄继续」提示也跟随「通知」开关，不会出现关了通知还在弹的情况。

### 二、提醒声音抽成共享模块 `src/sound.js`（应用 + 插件同一份）

原来 `src/taskReminder.js` 里内嵌了一段音频代码：一个写死 880 Hz 的 oscillator，加一个「自定义音频」分支。插件够不着，也没法加音效。

现在抽成 **`src/sound.js`**，成为提醒声音的单一事实源：

- `BUILTIN_SOUNDS` —— 音效目录（`id` / `label` / `note` / 音调序列），7 种音效全部用 Web Audio **现场合成**，不带任何音频资源文件，离线可用，也不增加包体。
- `playSound({ sound, volume, customAudio })` —— 统一播放入口，返回 `"custom" | "builtin" | "silent"` 便于测试与排错；自定义音频放不出来时**自动退回内置音**而不是静默。
- `resolveSound()` —— 未知 id 一律退回 `beep`。**默认音 id 保持 `beep`**，老用户设置里存的就是它。

三个消费方共用这一份：应用设置页「任务提醒」的提示音下拉、`src/taskReminder.js` 的到点提醒、插件的 `tide.sound`。设置页的提示音下拉也从原来的 2 项（内置 / 自定义）扩到 8 项。

顺手修掉一个体验问题：设置页点「试听」时，如果「启用任务提醒」是关着的，原来**一点反应都没有**。现在试听会忽略该开关，并在音量为 0 时给一个能听见的下限。

### 三、新增插件能力 `tide.sound` + 权限 `sound`

```js
tide.sound.presets()   // [{ id, label, note }] 内置音效目录
tide.sound.play({ sound, volume, customAudio })
```

- 需要 `manifest.permissions` 里声明 `"sound"`，`PLUGIN_PERMISSION_LABELS` 补了中文名「播放提醒音」。
- 番茄专注的 manifest 版本 0.1.0 → **0.2.0**，权限加入 `sound`，描述同步更新；已跑 `tools/sync-plugins.js`，桌面 / Android / 小程序三端清单一致。
- 插件不需要自己碰 `AudioContext`，也不用自带音频资源。

### 四、顺手修掉番茄专注在深色主题下的对比度问题

插件里原本把按钮文字写死成 `#fff` 压在 `var(--deep)` 上。深色变体里主色是被**提亮**的（经典主题 `--deep` 从 `#0F4C5C` 变成 `#21A7CA`），白字压上去只有 2.4:1 —— 和 v0.31.0 修掉的那批缺陷是同一个病。

已改为 `var(--on-deep,#fff)`（模式切换按钮、开始按钮、试听按钮），`#7E8B94` 改为 `var(--ink-2,…)`，进度环改用 `var(--mint)`，并在 SVG 上用 `style="stroke:…"` 因为**表现属性不支持 `var()`**。另外修掉「重置」在自定义分钟下不回退到自定义时长的问题。

### 五、回归与验证

- **新增 `scripts/test-pomodoro.mjs`**：在 Node VM 里注入 fixture 跑**真插件源码**，用一套极简 DOM 驱动 `render()` 与 `finish()`，覆盖：
  - 音效目录（id 唯一、默认音必须是 `beep`、每条音调频率 / 时长合法）
  - `resolveSound` 对未知 id 的兜底、`playSound` 在无 AudioContext 环境下吞异常返回 `silent`
  - 提醒开关四条分支（专注 / 休息 × 通知 / 声音）各自的调用情况，含「关掉通知后不再弹续接提示」
  - 配置自愈（`custom` 但音频丢失 → 退回默认音；已关闭的开关必须保留）
  - `render()` 能真的把界面建起来 —— 面板里的变量顺序问题会在这里直接抛出来
  - 源码守卫：不许再出现硬编码 `"#fff"`
- **真浏览器实测**：用无头 Chromium 加载真 `src/sound.js` + 真插件源码，**7 种内置音效全部返回 `builtin`**（合成链路无异常、无回退）；界面在浅色 / 深色 / 「已导入自定义音频」三种状态下各截一张。
- 测试脚本数 17 → **18**，`npm test` 全部通过；版本 `v0.32.0` 三端一致。
