# Le时间管理 v0.7.0

## 删除
- 删除「长辈照护」内置插件。
- 删除「安心日常」桌面视图和微信小程序页面/Tab。
- 删除对应 care 运行时、Tauri 语音桥、Android 同步脚本和旧测试。

## 通知加载优化
- 学习通收件箱增加本地 inbox 缓存，进入插件先展示缓存内容。
- 普通「快速刷新」改为增量分页：发现本地已知消息后停止继续向旧页翻页，避免每次都扫描最多 50 页。
- 新增「完整同步」按钮，需要核对历史时可强制从当前年度收件箱完整分页。
- 学校通知网站已有缓存时先渲染缓存，再触发非阻塞刷新。

## 完整性边界
- 学习通使用 notice.chaoxing.com/pc/notice/getNoticeList 主收件箱，并保留分页至 lastPage 的完整同步路径。
- 学校通知使用通用高校 CMS/公告链接解析器；特殊 JS 渲染、扫码、短信、动态加密统一认证仍需具体学校适配器。
- 本次构建环境没有用户账号/Cookie，不能对真实账号或特定学校服务端数据做端到端登录验证。
