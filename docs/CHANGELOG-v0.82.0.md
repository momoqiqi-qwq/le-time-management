# v0.82.0

## 交互修复与优化

- 工具栏 Alt+方向键在首尾边界也会阻止浏览器默认前进/后退；工具栏外快捷键保持原行为。
- 插件卡片只处理自身的 Enter/Space，内部按钮、输入框与输入法确认不再被父卡片抢走。
- 公共动效在 JS 和 CSS 两层统一遵守自身及祖先的 `data-motion="off"`，减少动效模式跳过无用计算；普通按钮反馈保留。
- 顶栏和左下操作条改为输入驱动的 rAF 合并更新：静止时不排帧、不轮询布局，松手同步处理最后坐标。
- 长按等待期间节点失效、拖拽中节点移除/隐藏、界面缩放改变时安全取消；取消和卸载清理待执行帧。
- 拖拽副本使用 inert，移除重复 ID 和后代 Tab 停靠点；开始拖动时清理嵌套按钮的残留按压/点击反馈。
- 修复真实 Chromium 触屏检查发现的捕获转移误取消：长按前轻微移动后，从子按钮转移隐式捕获不再中断拖拽。

## 影响范围与兼容性

- 影响主应用的工具栏、插件市场键盘操作和公共按钮动效；保留原按钮动作、现有排序存档、取消回滚与缩放补偿。
- 不改变任务数据结构、插件 API 或存储标识，无数据迁移，不重置用户配置。
- 微信小程序只按仓库规范同步版本号，没有新增上述主应用工具栏功能。
- 本轮不大规模拆分 shell.js，不新增产品运行时依赖，不生成 EXE/APK 安装包。

- 新增卡片激活与公共动效行为回归：自身/祖先 off、减少动效、输入法、嵌套控件、正常反馈与释放清理。
