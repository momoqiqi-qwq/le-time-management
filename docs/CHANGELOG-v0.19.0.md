# Le时间管理 v0.19.0

## 改了什么

### 一、交互动效增强

- 增强全局按钮反馈：按下时缩放回落，释放后轻微回弹，并从点击位置扩散低透明度波纹。
- 为关闭、取消、收起类按钮增加独立的短促反馈，关闭操作更容易被感知。
- 主页面切换改为带方向的退场与入场动画，前进和返回使用相反位移。
- 抽屉、居中弹窗、顶部面板、全屏设置和插件上下文菜单均增加对应的关闭动画。
- 动效仍遵循界面偏好与系统 `prefers-reduced-motion` 设置。

### 二、插件与界面一批改进

1. **插件重命名 / 删除改用应用内对话框**：右键菜单的「重命名」「删除插件」不再调用
   `window.prompt` / `window.confirm`（Tauri 里会弹出样式突兀的原生网页对话框），
   改为统一的应用内居中对话框（`appPrompt` / `appConfirm`，主题变量着色、Esc 取消、
   Enter 提交），删除确认按钮为红色危险样式。
2. **警大门户 1.3.1：修复自动登录 HTTP 500**。根因是自动登录链路的 `state.pending`
   只带了 `execution`，漏传 `username/password`，提交体变成 `username=undefined`
   导致服务端 500；账号密码验证码的预填不受影响。现在自动提交前带全凭据，并在
   `submitLogin` 入口加了缺凭据守卫（绝不提交空凭据）。
3. **微信推送 1.3.0：一键获取 Token**。PushPlus 配置区新增「↗ 一键获取 Token」按钮，
   直接打开官方「一对一消息」页（push1.html，未登录会先跳登录），登录后即可复制。
4. **学习通 2.5.0：课程页两级重构**：
   - 第一层按**学年**分 tab（如「2025-2026 学年」），每次打开默认显示**最近学年**；
     无开课时间的课程归「未知学年」tab 排最后；
   - 第二层学年内按完成状态分组，**纯色卡片背景**：红=未完成（开课学期在未来）、
     蓝=正在进行（当前学期）、绿=已完成（开课学期已结束），灰=状态未知；
     夜间主题有对应的深色版三色底；
   - 搜索框默认折叠为**放大镜图标**，点击展开，Esc 收起清空；有关键词时自动展开；
   - 页面写明状态是本地按「开课时间」推断的，学习通接口不返回该数据。

## 影响范围

- Windows、Android 共用前端界面。
- 小程序仅同步版本号，不改变交互实现。

## 数据迁移

- 无数据结构变化，不需要迁移。学习通课程页的学年/搜索视图状态为运行时状态，不持久化。
