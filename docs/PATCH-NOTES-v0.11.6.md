# v0.11.6 修改说明

## 1. 删除长辈照护 / 安心日常

- 移除遗留的 `elder` 主题入口。
- 删除对应 `elder-*` / `care-*` 样式。
- 当前主题保留：经典、清爽、夜间、深海蓝、樱花粉、松林绿、暮光紫、极简灰。

## 2. 直接跳转动画

- 主视图切换：先轻微淡出，再使用方向滑入动画进入目标页。
- 命令面板、插件直达、快捷功能盒等都复用该切换逻辑。
- 设置左侧分类点击后使用平滑滚动，并对目标卡片做短暂定位高亮。
- “减少动态效果”开启时不执行额外退出动画。

## 3. AI Base / API Key

设置中心新增 **AI 与自动任务**：

- Base URL
- 模型名称
- API Key
- 加密保存
- 测试连接
- 清除凭据

Base URL、模型、API Key 不写入 `data.json`，也不会进入普通数据备份。
Rust 后端使用 AES-256-GCM 保存到独立 AI vault；API Key 不回传明文，界面只显示掩码。

## 4. AI 自动任务

在 **收件箱与自动化 → AI 自动任务** 中可以创建多个规则：

- 每天
- 指定星期
- 每周一次
- 仅一次

支持两种创建方式：

1. 手动设置时间和执行说明。
2. 直接输入自然语言，例如：`每晚 22:30 检查没完成的任务，把最重要的 3 个安排到明天`，由 AI 解析时间和规则后再编辑保存。

到点执行时，只会把应用内任务、未来时间块和未处理收件箱摘要发给 AI。

## 5. AI 本地文件权限边界

AI 返回结果经过白名单解释器处理，只支持：

- 创建任务
- 更新任务
- 创建时间块
- 添加收件箱事项

AI 没有以下接口：

- 读取本地文件
- 写入本地文件
- 删除本地文件
- 执行系统 / Shell 命令
- 打开任意本地路径
- 调用插件文件读写能力

## 6. 调度行为

- 应用运行时每分钟检查一次 AI 定时任务。
- 网络失败后 10 分钟再尝试。
- 应用关闭时不会后台常驻执行；重新打开应用后，会补跑已经到时间但尚未执行的当前周期规则。
- “立即执行”用于手动测试，不会吃掉当天正常的定时执行。
