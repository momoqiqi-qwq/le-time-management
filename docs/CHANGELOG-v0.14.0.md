# Le时间管理 v0.14.0

## 改了什么

- 插件默认入口增加按插件区分的彩色底板。
- 侧栏插件和插件中心卡片支持右键菜单：重命名、更换图标、恢复默认外观、导入插件；用户插件还可直接删除。
- 顶栏的搜索、快捷入口、任务统计和窗口控制支持互相拖动换位，顺序保存在 `settings.topbarOrder`。
- 设置中的“界面与交互”新增“顶部任务统计居中”选项。
- 左下角设置入口缩小为纯图标按钮，不再显示“设置”文字。

## 影响范围

- Windows / Android 共用前端界面。
- 微信小程序仅同步应用版本号，不改变小程序导航交互。

## 数据迁移

无需迁移。新增的 `settings.pluginOverrides`、`settings.topbarOrder` 和 `settings.ui.centerTopStats` 均带兼容默认值；旧数据可直接加载。
