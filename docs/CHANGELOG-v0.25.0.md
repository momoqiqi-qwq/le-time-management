# Le 时间管理 v0.25.0

## 改了什么

- 课程表恢复时光课程表原版“选择学校”入口，支持本科/专科、研究生和通用工具分类、搜索与学校适配器选择。
- 内置官方 protocol-v2 学校索引作为离线列表，并在使用时读取官方适配脚本。
- 新增隔离的教务登录窗口：用户登录并进入个人课表后，可一键执行适配器并导入课程、学期配置和作息时间。
- 保留原有 XLSX/XLS/CSV/TSV/TXT/HTML 文件及粘贴表格导入方式。

## 影响范围

- Windows、Android 课程表插件与 Tauri 教务导入桥接。

## 数据迁移

- 无破坏性迁移；已有课表继续保留，在线导入结果合并到当前课表并自动去重。
