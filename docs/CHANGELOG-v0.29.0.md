# Le时间管理 v0.29.0

## 改了什么

### 考试日历新增「普通话水平测试（PSC）」

**为什么不是「一个考试日期」**

普通话水平测试**没有全国统一考试日期**。它由各省（市）语委与测试站分批组织，
频次从每年 1 次到每月开考不等，报名与测试时间各省不同。这一点在官方入口
国家普通话水平测试在线报名系统（bm.cltt.org）上可以直接看到 —— 上面挂的全是
「云南省 10–12 月社会人员测试通告」「宝鸡市 2026 下半年普通话测试」这类
**按测试站/地市分别发布**的计划，没有任何全国统一时间表。

因此插件**不编造全国统一考试日**，改为按「报名与测试窗口」建模：

- 新增筛选入口「普通话」（工具条 chips / 小程序下拉），分类为「语言」。
- 收录 3 个窗口条目，全部标记为**规则推算**（虚线边框、降透明度）：
  - 2026 下半年：`2026-09-01 ~ 2026-12-31`
  - 2027 上半年：`2027-03-01 ~ 2027-06-30`
  - 2027 下半年：`2027-09-01 ~ 2027-12-31`
- 条目名称写明「上半年/下半年各省分批」，类型标签为「分批报名」，
  右侧操作是「排进日程」+「报名」（点击打开 bm.cltt.org）。
- 数据结构里的 `rule` 字段写清了推算依据与不确定性来源，供后续采集核对。

**新增：报名窗口型条目的倒计时不编造截止感**

原先所有条目都走「进行中 · 第 N 天」/「N 天后」。一个跨 4 个月的报名窗口套上去
会变成「进行中 · 第 14 天」或「剩 109 天」—— 后者暗示了一个并不存在的报名截止日。
现在报名类条目（`type: registration` / `pre-registration`）单独一套文案：

| 状态 | 文案 |
| --- | --- |
| 窗口内 | 报名中 · 各省分批 |
| 窗口前 | N 天后开始报名 |
| 窗口后 | 本批已结束 |

同时这类条目不再显示「连续 N 天」，元信息行只留「语言 · 规则推算」。
该改动对将来采集到的真实报名批次同样生效。

**新增：滚动窗口排在同年的具体考试之后**

窗口起始日往往在几个月前，按日期排序会把一个 4 个月长的窗口顶到列表最前面，
把「5 天后」的 NCRE 挤到第二屏。现在列表按「年 → 是否报名窗口 → 日期」排序：
具体考试在前，滚动窗口收在同年末尾。先按年分桶是为了保证年份连续 ——
渲染端按年分组，年份一旦交错会出现两个同名分组。

**CET 报名提示改为通用结构**

原来「报名特别提示 + 直达入口按钮」是写死的 `if (cet4 || cet6)` 分支。
现在抽成 `SIGNUP_GUIDES` 映射（CET4 / CET6 / 普通话共用一套结构），
新增考试只需加一条映射。小程序端字段同步由 `cetNotice` 改名为 `signupNotice`
（`tools/test-miniprogram-core.js` 与 `miniprogram/tools/test-miniprogram-core.js`
两份副本的断言已一并更新）。

**任务动作支持普通话**

任务标题里出现「普通话 / PSC / 一甲 / 一乙 / 二甲 / 二乙」时，
「设为最近考试截止日」现在能匹配到普通话条目。

## 影响范围

- 桌面端插件 `public/plugins/exam-calendar/main.js`（插件版本 0.2.1 → 0.3.0）。
- 小程序 `core/pluginRuntime.js`、`pages/plugin/index.wxml`。
- 插件数据 `stats`：total 77 → 80，estimated 6 → 9（confirmed 仍为 71）。
- `tools/sync-plugins.js` 已重新生成小程序 `core/pluginData/exams.js`（80 条）。

## 数据迁移

无。新增条目是纯增量；`settings` / `reminded` / `events` 结构未变。
小程序端若停留在旧数据，重新执行一次 `node tools/sync-plugins.js` 即可。
