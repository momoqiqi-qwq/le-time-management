# Le时间管理 v0.25.1

## 改了什么

### 警大门户 1.4.1：修复自动登录 HTTP 500

自动登录偶发「登录未通过（HTTP 500）· 服务端会话异常」的根因是**残留会话污染**，不是验证码识别错：

- 识别错验证码时 CAS 返回的是 200 + 错误页（会被解析成「验证码错误」消息并换图重试），
  500 是服务端异常；
- 最典型来源：恢复的旧 `JSESSIONID` / 过期票据还在 Cookie 罐里，登录页的 `execution`
  与服务端会话对不上号，POST 提交直接 5xx。

修复：

1. 进入密码 + 验证码自动登录前，**丢弃恢复的会话，换全新 Cookie** 走完整链路
   （登录页 → execution → 验证码 → 提交），不带任何残渣；
2. 自动重试中遇到 **HTTP 5xx 自动再换新会话**，用剩余次数继续；
3. 诊断文案区分两类失败：5xx 提示「服务端会话异常（残留会话或 execution 失效）」，
   其余仍提示核对验证码。
