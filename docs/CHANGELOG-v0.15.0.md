# Le时间管理 v0.15.0

## 改了什么

学习通插件（`chaoxing-notify`）升到 **2.2.0**，主要给通知卡片补齐两条操作链路：

- **新增「移除」按钮**（收件箱、待办作业、分享码查询详情三处都有）。
  移除 = 只在这台设备上隐藏并记住，不触碰学习通平台数据：通知仍留在原始缓存里，
  顶部出现「恢复已移除（N）」，点一下全部还原，不需要重新同步。
  之前用「完整同步」会把移除过的通知再拉回来，现在不会了。
  按钮文案与悬浮提示都写明「不影响学习通平台，也不影响已创建的提醒」——
  早期草稿直接叫「删除」，容易被理解成真的删数据，定稿统一改成「移除」。
- **新增「浏览器打开（带登录态）」按钮**，替换原来只能开公开分享页的单一入口。
  插件会先读通知原始正文 HTML（`rtf_content`），挑出里面真正的**作业页 / 考试页 / 课程页**链接
  （作业页优先级最高），识别成功时卡片上会出现「已识别作业页」标记。
  打开前用本机会话探一次目标页：
  - 会话仍有效 → 直接用系统默认浏览器打开该真实页面；
  - 已失效 → 改走学习通 passport 跳板（`login?refer=<目标页>`），浏览器里登录一次后**自动回到该页面**。
  公开分享页（`sharewh3.xuexi365.com`）免登录可看，直接打开，不做跳板。
- **修复**：插件 manifest 漏声明 `openUrl` 权限，导致「打开通知」按钮此前点了没有任何反应
  （宿主抛「没有『打开外部链接』权限」）。本次一并补上。
- 收件箱统计由「已拉取 N」改为「显示 N / 共 M」，并单独显示「已移除 N」。

## 影响范围

- Windows / Android 共用前端与同一份插件源码，两端同时生效。
- 微信小程序：该插件在小程序侧为 `unavailable`，只同步应用版本号。
- 无需重新构建 Rust 侧：本次只改插件 JS 与清单。

## 数据迁移

无需迁移。插件存储新增 `ignoredIds`（本机忽略名单，上限 1000 条），
首次读取时缺省为空数组，老数据不受影响。

## 测试

新增 `scripts/test-chaoxing.mjs`（链接识别优先级、移除/恢复、manifest 权限、
带登录态打开的三条分支，并钉住「按钮必须叫『移除』、不许回退成裸『删除』」），
测试脚本总数 12 → 13，全部通过。
