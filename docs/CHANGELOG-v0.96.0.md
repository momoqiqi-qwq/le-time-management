# U-Time v0.96.0

## 完成内容

- 一卡通改为独立 OAuth 自动登录，首次成功后将学/工号、密码与访问令牌加密保存在本机密钥库。
- 打开一卡通视图时自动恢复登录；令牌失效后使用保存的密码重新登录，无需重复输入。
- 充值统计改为读取一卡通平台账单接口，自动识别充值流水并计算总充值量及年、月、日汇总。
- 移除本地手工“记一笔”和删除记录，保留平台账单的只读离线缓存。
- 一卡通账单、充值、账户中心继续在 U-Time 应用内显示。

## 影响范围

- Windows、Android：警大门户通知插件的一卡通视图。
- 小程序：该插件仍不可用，无变化。

## 数据迁移

- 无破坏性迁移。旧的手工充值台账不再参与统计，也不会自动上传到一卡通平台。
- 一卡通凭据仅存放于插件加密密钥库，不进入普通设置文件或备份。
