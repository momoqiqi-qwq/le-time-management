# Le时间管理 v0.26.1

## 改了什么

### 原版课程表：触控板双指滑动适配

- 原生课表在输入事件初始阶段识别高精度触控板滚动，垂直双指滑动直接驱动课表滚动位置。
- 仅拦截纵向位移明显大于横向位移的手势，横向双指滑动继续用于切换周次。
- 滚动到顶部或底部后不继续吞掉事件，避免产生“卡住”的感觉。
- 嵌入 Windows 子窗口时，鼠标进入或按下课表区域会主动获取输入焦点。
- 恢复 Tauri 插件宿主中的原版时光课程表渲染入口，避免后续构建退回 Web 复刻界面。

## 影响范围

- Windows 原版时光课程表嵌入界面。
- Android 的触摸拖动仍由 Compose 原生滚动处理，行为不变。

## 数据迁移

无。
