# v0.36.8 · 设置新增「底栏高度」调节

发布版本：v0.36.8（三端同源，无插件变更）

## 新功能

- **设置 → 界面与交互 → 底栏高度**：三档「紧凑 / 标准 / 宽松」，控制手机端底部导航栏的
  按钮高度、图标大小与内容区底部预留（紧凑 47px / 标准 53px / 宽松 61px 实测总高），
  即点即生效并持久化；桌面端布局不受影响。
- 实现：`uiPreferences.navBarSize`（normalize 校验非法值回标准档）→ `data-navbar` 属性 →
  `--nav-btn-h / --nav-ic / --nav-pad` CSS 变量，底栏与设置齿轮全部改为消费变量。
- `test-ui-preferences.mjs` 补 navBarSize 三档 + 非法值守卫。

## 验证

- 22/22 测试通过。
- 无头浏览器（Android UA + 390×844）实测三档：railH 47/53/61、btnH 40/46/54、icW 19/22/26。
