# v0.66.0 · 竞赛消息雷达多源化：三家内置源可一键切，还能自己贴网址加源

## 版本号为什么是 0.66.0

工作树里同时有两笔未提交的在建改动，各自带自己的 CHANGELOG：`v0.64.0`（本笔最早写的号，被后来的会话跨过去了）
与 `v0.65.0`（别的笔，尚未落说明文件）。本笔是**新增功能**，按铁律一走 minor、不压进别人的号里，
所以取下一个空号 **0.66.0**：`package.json` 写 0.66.0 → `sync-version.js` → `package-lock.json` 手改两处。
提交顺序若与本笔交错，以最后提交者为准再同步一次即可。

## 先说清楚这是什么

原来这个插件只认一家 —— 摩课云竞赛平台（`gxxsjs.com`）的接口，代码里 `API` / `DETAIL` 两个常量写死。
本版把它改成**多源**：

- **源那一排**（在「类型」「月份」之上）列出所有可用源，点一下就切过去，切完立刻抓第 1 页；
- 内置源从 1 家加到 3 家：**摩课云竞赛**（默认，本校在用）、**赛氪竞赛广场**、**我要参赛网**；
- 「＋ 添加源」可以贴任意一个竞赛列表网址，**自动识别形态**：RSS / Atom 订阅、返回 JSON 的数据接口、
  普通网页列表都能吃；添加时真抓一次，成功就报「已添加，抓到 N 条」并切过去，失败就把原因写在浮层上。

## 三家源的形态完全不同，这是本版全部复杂度的来源

| 源 | 列表地址 | 形态 | 要害 |
|---|---|---|---|
| 摩课云 | `/prod-api/home/competition/news/page?pageNum&pageSize` | JSON，`code:0` 包 `data.records` | `newsType` 是 `202.204.208` 这类点分复合标签，按包含关系收敛成「平台通知 / 赛事动态」 |
| 赛氪 | `https://www.saikr.com/contests` 页面**抓不到东西**，列表在 `apiv4buffer.saikr.com/api/pc/contest/lists?page&limit&…` | JSON，`data.list` | 页面是 Vue/Vite 空壳（实测只回 4.6 KB、一个 `<a>` 都没有），必须直接打接口；时间**只给 Unix 秒**；详情地址是 `vse/xxx` 相对形式 |
| 我要参赛网 | `https://www.52jingsai.com/bisai/`，翻页 `/bisai/index.php?page=N` | **GBK** 编码的 Discuz 门户 HTML | `<dl class="bbda list_bbda">` 一块一条；页面带 `<base href="https://www.52jingsai.com/">`，条目链接是裸的 `article-24056-1.html` —— 按页面路径 `/bisai/` 拼会得出 404（实测两地址：根 `/article-24056-1.html` 200，`/bisai/article-24056-1.html` 404） |

编码这一头不用插件管：`http_get`（Rust 侧 reqwest + encoding_rs）按「响应头 charset → HTML `<meta>` → UTF-8 兜底」解码，
所以 GBK 的列表页进到插件里已经是正常中文。

**没有新增任何权限**：三家源用的都是 manifest 里早就声明的 `http` / `openUrl` / `storage` / `tasks` / `blocks` / `timeParse` / `events`。

## 改了什么

### ① 条目模型统一成一份

每个源把自家字段折成同一套：`{ id, rawId, title, type, time, deadline?, status?, snippet, cover, url }`。
渲染 / 筛选 / 转提醒 / 广播只认这份结构，换源不用改任何下游代码。

- **类型 chip 改成由数据长出来**，不再是写死的四颗。摩课云还是「平台通知 / 赛事动态 / 其他」；
  赛氪是接口给的 `level_name`（全国性 / 省级 / 校级 / 自由…）；我要参赛网是页面的「分类」（科技创新 / 公益大赛 / 设计比赛…）。
  只有 `lv:` / `cat:` 前缀的动态类型用前缀隔开，避免和摩课云的 `n202` 撞。
  自定义源没有类型维度 ⇒ **整行收掉**，而不是留一个孤零零的「全部」。
- **时间一律归一到补零的 `YYYY-MM-DD[ HH:mm]`**。月份分组是 `time.slice(0, 7)`，
  我要参赛网页面里写的是 `2026-9-17`，不补零会切成 `2026-9-` —— 分组和筛选一起废。
- **卡片多两处信息**：`截止 2026-10-17 22:00`（红）、`正在报名 / 即将截止`（绿）。只有源给了才渲染。
- 转提醒：正文里 parseWhen 解不出时间时，**用接口给的报名截止日兜底**，并且只取「哪天」不取几点
  （截止时刻实测是 `23:59` / `00:39` 这类半夜点，按它提醒等于睡梦里收通知），提醒落 09:00，
  toast 里写明「（按报名截止）」。

### ② id 必须按源隔离

三家的 id 都是自增数字，**撞号是必然**。原来是裸 `newsId` 存进 `seen`，多源之后在赛氪读过一条，
摩课云同号码那条会被一起标成已读。所以条目 id 一律 `源id:原始id`。

配套的两处迁移（都是读的时候做，不写迁移器）：

- `seen` 里的裸 id（v0.3.x 只有一家的时代写的）⇒ 补 `mokeroad:` 前缀。不补的话升级一次等于全部消息复活成 NEW。
- `knownIds` 原来是**一维数组**（判「新消息」的快照）⇒ 归到 `mokeroad` 名下，并改成按源分存的字典
  `{ mokeroad: [...], saikr: [...] }`。这样切来切去不会把别家的旧消息重推一遍，
  而新源第一次抓取仍走「只记快照、不广播」。

### ③ 切源时的筛选归属

`类型` 和 `月份` 是**跟源走的**（`n202` 在赛氪这边根本不成立），换源直接归「全部」并落盘；
`关键词` / `只看未读` / `封面图` 是**跟人的**，保留。
残留关键词命不中时，空态照旧把生效中的筛选列出来 + 给一键清除 —— 这是 v0.60.1 那条不变量，不能因为多源退化。

抓取加了 `fetchSeq` 令牌：切源瞬间上一家的响应还在路上，回来发现令牌不对就整包丢掉，
否则会把摩课云的条目混进赛氪的列表。

### ④ 自定义源的自动识别（`fetchGeneric`）

依次尝试，谁先出条目就用谁：

1. **RSS / Atom**：`<rss|feed|rdf>` 开头即认。日期解析走 `parseDateField`，
   RFC 822（`Fri, 18 Sep 2026 09:30:00 +0800`，RSS 2.0 的标准写法）只有 `Date.parse` 认得，正则抠不出来；
   ISO / `20260918` / 14 位 `20260918111500` / Unix 秒也都能落。
2. **JSON**：BFS 找第一个「对象数组」（嵌在 `data.list`、`info.rows` 里都找得到），
   字段靠**键名猜**，两层：先 exact-ish（`title` / `url` / `time`），再模糊（`actName` / `showTime` / `picUrl` / `memo`）。
3. **HTML**：每个 `<a>` 当一行，标题取链接文字，日期只在本行自己的文字里找，带日期的优先。
   识别不出条目时，如果页面挂了 `<link rel="alternate">` 订阅声明，**追一跳**去抓那个 feed。

抓不通的提示要说人话（实测赛氪页面就是这么暴露的）：

- 零链接 / 带框架标记 ⇒ 「这是 JS 渲染的页面…改抓它的数据接口：F12 → Network → 筛 Fetch/XHR」。
  框架标记不一定在前 4 KB（赛氪的 Vite 产物就没有 `__NUXT__` / `data-v-app`），所以**按零链接也判一次**。
- 有链接但认不出列表 ⇒ 直说「链接太少或都不是竞赛列表」。
- **抓不通绝不落库**：留下一个抓不出东西的源，只会在每次刷新时重复报错。

两处实测调出来的判据（都在测试里钉着）：

- **行窗口要收边**。±300 字符的裸窗口会让侧栏菜单把上一行的日期借过去 ——
  实测我要参赛网的「2015年优秀大使评选」这类年份菜单项被当成竞赛条目混进列表。
  现在取「行结束标签（`</li>` / `</tr>` / `</div>`…）」和「相邻链接」两道边界里更近的那个。
- **没有日期的行要成规模才有资格留下**。带日期的行 ≥ 8 条时，无日期的一律丢掉。
- **内置三家已覆盖的站，不许再当自定义源加一遍**（通用解析认得出的条目比内置适配器少，也不带类型 / 截止时间）。
  实测贴 `www.saikr.com/contests` 会走到「空壳报错」，现在直接提示「『赛氪竞赛广场』已经是内置源，点上方那一排」。

### ⑤ 浮层挂在哪

「＋ 添加源」的浮层 `append` 到插件自己的 `.gx-wrap` 上，**不碰 `document.body`**：
宿主切视图会把容器整个换掉，挂 body 上的浮层会变成摘不掉的孤儿。
`buildUI` 里顺手把 `dialog` 指针清掉（旧的 `el.innerHTML = ""` 已经把浮层从 DOM 上摘走了，
不清的话 `openDialog` 以为还开着、再也点不出来）。

## 三处实现约束，别改回去

1. **解析一律字符串正则，不用 DOMParser。** 与 RSS 信息流同一套取舍：中文站常缺闭合标签、属性里塞未转义的 `&`，
   DOMParser 一遇 `parsererror` 整源报废；纯字符串实现还能在 node 里直接跑测试 —— 这是本插件可测的前提。
2. **`toText()` 先挖 `<script>/<style>` 再去标签**，顺序反了会把 JS 正文留在文本里（`<[^>]*>` 先把尖括号吃掉）。
3. **自定义源只取第 1 页**，状态行明说「自定义源只取第 1 页」。通用解析没有可靠的翻页规律，
   宁可不翻，也不要猜一个 `?page=N` 去抓回一整页导航。

## 影响哪端

- **Windows / Android**：竞赛消息雷达整个视图。插件清单 0.3.1 → **0.4.0**，
  入口 URL 带 `?v=`，APK 覆盖安装后 WebView 才会弃掉旧 `main.js` 缓存。
- **微信小程序**：**仍只有摩课云一个源**（`wx.request` 受微信公众平台「request 合法域名」白名单限制，
  新增 `saikr.com` / `52jingsai.com` 要去小程序后台配域名，而自定义源等于要放行任意域名，做不到）。
  但手机端的 `loadGx` 改了一处**必需的兼容**：桌面端把 `seen` 写成 `mokeroad:123` 之后，
  两端共用同一份 `data.json`，手机端读回来必须把前缀摘掉再比，否则已读全不命中、整列表复活成 NEW。
  写回时仍写裸 id —— 桌面端读回来会自己补回前缀。插件页的「使用说明」也多了一条，讲清切源要在桌面端做。
- `manifest.json` 的 version / description 变了 ⇒ 已重跑 `node ../tools/sync-plugins.js`，
  桌面 `src/pluginCatalog.js` 与小程序 `core/pluginCatalog.js` 同步。

## 有没有数据迁移

**插件 storage 内部自洽，`src/migrations.js` 不用动。** 读的时候做三件事：

| 键 | 旧格式 | 新格式 | 处理 |
|---|---|---|---|
| `seen` | `[123]` 裸 id | `["mokeroad:123"]` | 读回时补前缀（已带冒号的原样放过） |
| `knownIds` | `[123]` 一维数组 | `{ mokeroad: ["mokeroad:123"], saikr: [...] }` | 数组 ⇒ 归到摩课云名下 |
| `filter.type` | `n202/n203/other` | 同左 + 动态 `lv:xxx` / `cat:xxx` | `sanitizeFilter` 放行三种形态，未知值仍归 `all` |
| `source` / `customSources` | — | 新增 | 缺失即默认摩课云 + 空列表 |

### `scripts/test-gx-news.mjs` 从 4 段扩到 8 段

原有那四条筛选自愈断言**一条没删**（它们正是多源改造最容易碰坏的地方），只把 `seen` 那条改成同时压住裸 id 迁移。
新增部分：

- **② 三内置源各拿真响应形态喂**：赛氪的 Unix 秒要补零、截止要显示、`level_name` 长出类型 chip；
  我要参赛网的 `list_bbda` 块、`2026-9-17 → 2026-09-17`、`||` 分隔正文成摘要、`分类` 成类型、id 取 article 编号。
- **③ 切源**：默认仍打摩课云、没切源前**不许**请求别家；切过去立刻抓第 1 页、列表整换、`source` 落盘、
  类型/月份归「全部」而关键词保留；残留关键词命不中时空态列出生效筛选 + 一键清除。
- **④ id 隔离**：摩课云 `1` 已读之后切到赛氪，赛氪条目必须还是 NEW。
- **⑤ 自定义源三路识别**：RSS（RFC 822 + ISO 两种日期、guid 成稳定 id、无类型时整行收掉）、
  JSON（`info.rows` 嵌套数组、`actName` / `showTime` / `memo` 靠键名猜中、相对地址按接口地址解析 —— 走一遍「打开 ↗」看真正解析出的绝对地址）、
  HTML（带日期优先、导航「首页/登录/更多」不许混进来、9 条带日期时侧栏链接一律丢掉）、
  空壳（报「空壳」+「接口」，而不是显示成一张空的正常列表）。
- **⑥ 添加浮层全流程**：成功 ⇒ 落库 + 切源 + toast 报条目数；抓不通 ⇒ 原因留在浮层、**不落库、不切源**；
  重复地址拦下；缺协议不发请求；内置站拦下。
- **⑦ 广播**：老数组快照迁到摩课云名下、新源首抓不广播、来回切源零重复推送。
- **⑧ 转提醒**：`due` 必须等于**卡片上显示的那一天的**截止日（列表按时间倒排，两条截止日不同，
  断言要按 id 抠对应那张卡），块落 `09:00`，toast 写明「按报名截止」。
