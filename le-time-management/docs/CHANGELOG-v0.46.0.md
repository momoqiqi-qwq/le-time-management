# v0.46.0 版本说明

发布日期：2026-09-16

> 本版改动：全局搜索 / 命令面板针对手机端（APK）补齐视觉与触控缺口 ——
> 搜索框放大镜换成真图标、结果条目按类型加图标、插件条目用插件自己的图标、
> 新增 ✕ 关闭按钮（手机上没有 Esc 键，此前只能点面板外空白处收起）；
> 学校通知插件展开正文「闪一下」修复，展开 / 收起改为真正播放的平滑动画。
> 本版本同时包含此前未提交的 v0.45.2（学校通知卡片重排）与
> v0.45.3（课程块内不再显示时间）两批改动，将随同一提交一并发布。

## 改动 · 命令面板移动端适配

### 问题

命令面板在手机上：

1. 搜索框左侧的放大镜是**纯文本「⌕」字形**，字号小、观感单薄；
2. 结果条目的类型徽章（命令 / 导航 / 任务 / 时间块 / 插件…）只有文字，没有图标；
3. 右上角是桌面端才有的 `Esc` 键帽提示，**手机上没有任何可见的退出方式**
   （只能点面板外空白处，键盘弹起时很难点到）；
4. 底部提示「↑↓ 选择 · Enter 打开 · Ctrl+K 随时呼出」在触屏上全部不适用。

### 改动

- **搜索框图标**：纯文本「⌕」换成内联 SVG 描边放大镜（跟随 `currentColor`，
  深浅主题自动适配，不引入 Icons8 PNG、零额外加载）。
- **关闭按钮**：搜索行新增 ✕ 按钮（`.cmd-close`），点击即关闭面板；
  `Esc` 键帽仅在桌面（> 700px）显示。
- **类型图标**：结果条目的类型徽章内置同风格内联 SVG 图标 ——
  闪电（命令）、罗盘（导航）、对勾圆环（任务 / 已完成任务）、时钟（时间块）。
- **插件条目用插件自己的图标**：插件 / 已停用插件条目的徽章显示该插件的随包图标
  （`/icons/plugins/<插件ID>.png`，Icons8 Color 彩色风格，与插件中心同一套）；
  没有随包图标的（外来插件等）自动回落**齿轮** SVG。已停用插件的图标降透明度显示。
- **窄屏（≤ 700px）布局**：类型徽章收成纯图标圆片（文字隐藏，14px 图标），
  `↵` 回车提示隐藏；底部提示切换为触屏文案
  「点按条目直接打开 · 点按空白处收起」。桌面布局不变。
- 键盘导航（↑↓ / Enter / Esc / Ctrl+K）、搜索评分与数据来源完全不变。

## 改动 · 学校通知展开/收起动画修复（school-notice 插件 1.3.0 → 1.3.1）

### 问题

展开通知正文会「闪一下」。根因：展开 / 收起 / 正文加载每一步都调用 `paint()`
整体重建列表 DOM —— 新插入的条目直接带着 `.open` 终态出现，CSS 过渡
（`grid-template-rows: 0fr → 1fr`）在元素初始渲染时**根本不会播放**，
观感是瞬时跳变；附带整个列表重绘（favicon 重载、滚动位置抖动、hover 态丢失）。

### 改动

- **展开 / 收起不再重绘**：新增 `setItemOpen` / `setItemDetail`，只对被点击的
  条目就地切换 `.open` 类，让既有元素自己的过渡真正播放（0.42s 缓动 +
  箭头旋转 + 边框 / 阴影渐变）；`aria-expanded`、按钮文案同步就地更新。
- **正文抓取就地填充**：点击展开立即在详情容器内显示「正在读取正文…」，
  抓取完成后只替换详情内容，列表其余部分纹丝不动；抓取期间列表若被
  整体重绘（刷新 / 切站点），旧元素失效则安全跳过。
- **展开中的条目关闭 `content-visibility: auto`**（改为 `visible`），
  避免内容可见性 containment 干扰展开过渡。
- 删除条目、刷新、搜索等其余动作仍走整体重绘，行为不变。

### 验证

真实数据（北航信息门户接口快照）无头 Chrome 探针：展开 / 收起 / 缓存再展开
三轮采样确认——**列表 DOM 未重建**（哨兵元素全程存活）、状态与文案正确翻转、
过渡规则（`grid-template-rows, opacity, margin-top` / 0.42s）就位、
出帧模式下展开终态渲染正确（桌面 1180px 与 390px 窄屏双截图）。

## 修复 · 学校通知插件「登录配置 / 登录并读取通知」点了没反应

### 问题

学校通知网站插件的两个登录按钮**点击后界面毫无变化**：不报错、不提示、
登录框也不刷新。根因不在按钮的事件绑定，而在插件的 `manifest.json`
**漏声明了 `notify` 权限**，而插件把「报错」也交给了 `tide.notify`：

```js
try { ... await prepareLogin(site); }         // 失败 → throw
catch (err) { tide.notify(err.message); }     // ← 这一句自己也 throw（没有 notify 权限）
```

宿主的 `requirePermission`（`src/pluginHost.js`）是**抛错**而不是静默降级，
于是错误提示自己又抛一次，异常逃到 `unhandledrejection` —— **动作与提示一起消失**。
同一原因还让 `submitLogin` 里这行失效：

```js
loginRuntime.delete(site.id); tide.notify("登录会话已建立，正在读取学校通知"); await refresh(false);
//                              ↑ 这里 throw ⇒ 后面的 refresh 永远不执行 ⇒ 登录成功也读不到公告
```

实测（真 Chrome + 真 `webContent.js`，mock 宿主按真规则校验权限）：
点「登录并读取通知」→ 登录 POST 成功 → `UNHANDLED_REJECTION: 插件"学校通知网站"没有「notify」权限`，
界面零变化、登录框不收起、公告 0 条。

### 改动

- **`school-notice/manifest.json` 补 `notify` 权限**（v1.3.0 → v1.3.1）。这是根因修复。
- 插件内新增 `toast()` 包装（内部 try/catch），10 处 `tide.notify` 全部改走它 ——
  **提示失败不再吞掉动作本身**，同类权限/宿主异常不会再让按钮「静默失效」。
- 「登录配置 / 刷新验证码」加专属忙碌态：按钮显示「读取中…」并禁用
  （此前拉登录页最长要等 30 秒，全程无反馈，看着就像坏了）。
- 登录失败原因**常驻显示在卡片上**（`loginErrors`），不再只靠一闪而过的 toast；
  识别不到表单时也给出「改用登录网址 / 该站需单独适配」的下一步提示。
- 登录提交顺序修正：先读输入框再 `paint()`（`paint()` 会重建 `host.innerHTML`，
  顺序反了会把刚填的账号密码清空），并在清掉 `busy` 之后才 `refresh`。
- 登录框已填内容按站点记在内存里（`loginDraft`），「刷新验证码」「登录失败重试」
  重绘后自动回填；登录成功或删除站点时清除。密码仍只留在内存，不落盘。

### 顺带修掉同一根因的另外两个插件

新增守卫测试 `scripts/test-plugin-permissions.mjs`：扫描每个插件源码里**真实调用**的
`tide.*` API，与 `manifest.permissions` 对账（新增命名空间/API 时会强制同步本表）。
一上线就抓到另外两处同类漏声明：

- `web-collector`（v1.2.0 → v1.2.1）缺 `notify`：收藏成功/失败、图标获取结果的提示全部被吞。
- `plugin-guide`（v1.3.0 → v1.3.1）缺 `notify`：打开链接失败、文档保存结果的提示全部被吞。
- `exam-calendar`（v0.3.1 → v0.3.2）缺 `timeParse`：`tide.util.guessQuad()`
  （「设为最近考试截止日」等动作）会直接抛错。

## 新增 · 学校通知：站点标签页右键菜单

### 背景

站点多了以后，标签页在顶上、操作按钮在下面卡片里，要动某个站点得先点标签切过去、
再回到卡片点按钮。右键标签页直接把同一组操作摆到鼠标处。

### 改动

- 站点标签页支持**右键**（`contextmenu`）弹出菜单，项目与卡片按钮**同名同序**：
  刷新通知 / 登录配置 / 编辑 / 打开网站 / 分隔线 / 删除站点（危险色）。
- **右键即切换**：右键哪个站点就把它切成当前站点，菜单动作与卡片按钮共用同一套实现
  （它们都作用于 `active()`）—— 否则右键「通知公告」会去刷新「北航信息门户」。
- 菜单定位在光标处并**按视口夹紧**，贴右/下边不会被窗口裁掉。
- 收起方式：点别处 / `Esc` / 页面滚动 / 左键点任意标签。
  document 级监听用 `tabMenuDismissBound` 闸门只绑一次（宿主元素会随 render 重建）。
- 只对**标签页**`preventDefault`：别处保留浏览器原生右键菜单（右键往输入框粘网址还要用）。
- 标签页加 `title` 提示「右键：刷新 / 登录配置 / 编辑 / 打开 / 删除」。
- 卡片「删除」的内联逻辑抽成 `removeSite(site)`，卡片与右键菜单共用一份（两处实现迟早走岔）。
- 插件 v1.3.1 → **v1.4.0**。

## 影响端

- 桌面（Windows / macOS / Linux）与 Android WebView 共用同一份
  `src/commandPalette.js` + `src/styles.css`，两端同步生效；
  桌面端额外获得一个可点击的 ✕（不影响原有快捷键）。
- 插件修复对桌面 / Android 同时生效（两端同源 `public/plugins/**`）。
- 右键菜单是**鼠标交互**：Android 触屏上长按不会触发 `contextmenu`，
  手机上仍用卡片上的同一组按钮（功能不缺）。如需触屏长按唤起，另做。
- 小程序：不涉及（无命令面板；school-notice / web-collector 在小程序端不可用）。

## 数据迁移

无。纯界面与权限声明改动，存储键与数据结构零改动。
