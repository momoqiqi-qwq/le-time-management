# v0.70.0 · 横向时间轴不再叠字：画布宽度改按事件数撑出来

## 需求

> 时间轴里的很多样式都需要修改，否则会重叠。（附截图：一排日期徽章只看得见「2026-0」，
> 上下两排卡片的标题互相压住）

只影响 **Windows / macOS 桌面端**的「横向时间轴（年表）」视图。
Android 与小程序走的是纵向年表（`.chronicle-vertical` / `.cv-item`），本来就不按横向位置排布，不受影响。
**无数据迁移** —— 纯布局与样式，store 一个字段都没动。

## 重叠是怎么来的：不是某条 CSS 写错

在 dev server 上灌进与截图同量级的数据（26 条事件，跨 9/12–9/19）实测：

| 实测项 | 结果 |
|---|---|
| 画布宽度 | 1500px（`styles.css` 里写死的 `min-width`） |
| 相邻事件前进量 | 89% 预算 ÷ 25 个间隔 = 3.56% ⇒ **53.4px** |
| 卡片宽 | **150px** ⇒ 同侧相邻卡（隔两槽，106.8px）**互叠 43.2px** |
| 日期徽章宽 | **70.2px**（「文字大小」130% 时 86.3px）⇒ 相邻徽章**互叠 16.8px** |
| 重叠对数 | 49 对（卡片 24 + 徽章 25，几乎全叠） |
| 卡片高度 | 无行数上限，130% 字号下从 108px 长到 **143.6px** |

两条几何约束叠在一起才致命：

- 卡片上下交错，所以同侧相邻卡隔**两**槽 —— 要 150px 就得给到 75px 一槽；
- 但**上下两排的日期徽章都骑在同一条轴带上**（`.up .ce-date` 与 `.down .ce-date`
  解析出来都在轴心 ±1px），相邻徽章只隔**一**槽 —— 70px 宽的徽章塞进 53px 的槽，
  后一张盖掉前一张的后半截，就只剩下截图里那排「2026-0」。

根因是「画布宽度写死 + 位置按百分比算」：26 条事件要 26 × 150 = 3900px 才不叠，
画布只给 1500px。**百分比预算再怎么调都救不回「槽宽 < 内容宽」**，
所以只能从画布宽度这一层解，而不是继续改 CSS 数值。

## 改了什么

### 1. 画布宽度按事件数撑出来（`timeViews.js` `chronicleView`）

一槽的下限由卡片宽算出：`SLOT_MIN = (CARD_W + 18) / 2 = 84px`（同侧隔两槽 ⇒ 168px ≥ 150px 卡片 + 18px 缝）。
画布宽 = `max(1500, 需要的像素 ÷ 89%)`，挂到 `.chronicle-canvas` 的内联 `min-width` 上，
密度交给本来就在的 `.chronicle-scroll` 横向滚动承担。

`CSS 里那条 min-width:1500px` 删掉了 —— 宽度现在只有一个来源。
卡片宽也改成 JS 发下来的 `--tl-card-w`，槽位算的就是它，两边不会脱节。

实测 30 条事件：画布 2737px，一槽 84px，**卡片 0 叠、徽章 0 叠**（100% / 130% / 150% 三档字号各测一次）。

原来那句兜底压缩步长的 `step = Math.min(MIN_STEP, …)` 保留不动：画布既然按需求撑开了，
它永远命中不到 `MIN_STEP` 以下，退化成安全网。

### 2. 日期徽章恒写 MM/DD，跨年时年份另起一行

完整日期 `2026-09-12` 宽 70px，而槽位只有 84px —— 一屏内相邻徽章只隔一槽，必然互盖。
改成 `09/12`（实测最宽 57.2px @150%），完整日期仍在卡片第二行和悬浮 `title` 里。

跨年时把年份塞成徽章内的第二行（`.ce-year`），而不是写成 `2026/09/12` 前缀 ——
前缀会把徽章拉宽一倍，而槽位是按 MM/DD 算的，轴带就又开始互盖。换行只让徽章长高几像素，
轴带上下都有富余（实测 150% 下双行徽章 36px 高，与上排连线末梢还剩 4.7px）。

**槽宽因此是个常数，不随「文字大小」设置变。** 这点是刻意的：改文字缩放不会重渲染这个视图
（`tide:ui-preferences-changed` 全仓库没有监听方），任何「渲染时读一次 CSS 变量」的算法
都会在改完字号后留下一张旧画布 —— 实测就会重新叠出 14px。

### 3. 卡片文字封顶两行 + 强制断词

`.ce-card b` 与 `.ce-card span` 各限两行（`-webkit-line-clamp:2`）。
卡片下方的连线、圆点、日期徽章全按固定偏移排，卡片一长就顺着把连线推进徽章带里 ——
竖向重叠的来源就是它。补上 `overflow-wrap:anywhere`：卡片只有 150px，
一条不沾空格的长链接能横着穿出邻卡。

### 4. 顺手修掉一条死规则：下排的连线原本指向外侧

`.chronicle-event.down .ce-stem { order:-1 }` 想让下排「连线在上、卡片在下」，
但父级 `.chronicle-event` 是块级布局，**`order` 在非 flex 容器里完全无效**。
结果下排的连线挂在卡片下面，指向远离中轴的方向。
给 `.chronicle-event` 补 `display:flex; flex-direction:column` 让它真正生效。
实测：连线 420→490、卡片 490→604，连线末梢正好接上卡片顶边。

## 影响面

| 端 | 影响 |
|---|---|
| Windows / macOS | 横向时间轴（年表）视图：不再叠字；比容器宽时横向滚动（本来就有滚动条） |
