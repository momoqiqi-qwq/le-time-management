# v0.45.2 版本说明

发布日期：2026-09-16

> 本版一处改动：school-notice 插件通知卡片参考「警大通知」（cppu-notify）的卡片设计重排 ——
> 消除右侧竖排按钮列撑出的大片空白，卡片信息密度与警大通知对齐。（插件 1.2.0 → **1.3.0**）

## 改动 · 学校通知卡片重排（参考警大通知）

### 问题

北航等站点读出的条目卡片高度被**右侧竖排的四个按钮**（打开 / 展开 / 转提醒 / 删除，
一列约 130px）撑开，而左侧文字只有标题 + 日期 + 一行摘要，卡片下半全是空白；
且北航（JSON 接口型）的摘要是「新闻资讯, 2026-09-16 19:01」这种伪摘要，
与单独一行日期重复显示。

### 改动（对齐 cppu-notify 的卡片结构）

- **单列卡片**：删掉 `grid-template-columns:1fr auto` 双列与竖排按钮列
  `.sn-item-actions`，卡片高度回归内容本身（`contain-intrinsic-size` 同步改
  `auto 74px`，与警大一致）。
- **标题整行可点**：新增 `.sn-heading`（对应警大 `.pp-heading`）—— 点击标题
  展开 / 收起正文，带 `aria-expanded` 与 `aria-label`。
- **meta 行内联**：新增 `.sn-meta-row` + `.sn-tag`（对应警大 `.pp-meta` / `.pp-tag`），
  分类（通知 / 公告 / 新闻资讯…）渲染成标签，日期并入同一行。
- **伪摘要去重**：摘要形如「分类, 日期 时刻」（长度 ≤ 日期 + 12 字符）时不再整段显示，
  只把其中的**时刻**补进 meta 行日期后面；真正的正文摘要照旧显示（双行截断）。
- **展开按钮**：改为警大 `.pp-expand` 同款（文字 + ⌄ 箭头，展开时箭头旋转 180°）。
- **操作收进展开区**：「打开原文 / 转为提醒 / 删除条目」改为横排按钮行
  `.sn-item-acts`（对应警大 `.pp-detail .pp-act`），只在展开后出现。
- **展开动画**：正文区换用警大 `.pp-detail-shell` 的 `grid-template-rows: 0fr → 1fr`
  过渡 + 详情上滑，展开 / 收起不再瞬变。
- 窄屏（≤720px）：标题与操作按钮给到 44px 触控高度；旧的两列/按钮换行规则删除。
- 展开取正文的逻辑（30s 看门狗、缓存、失败提示）与数据存储完全不变。

## 影响端

- 桌面（Windows / macOS / Linux）与 Android WebView 共用同一份 `public/plugins/school-notice/main.js`，两端同步生效。
- 小程序：不涉及（school-notice 在小程序端为 `unavailable`）。

## 数据迁移

无。存储键与数据结构零改动，纯界面重排。
