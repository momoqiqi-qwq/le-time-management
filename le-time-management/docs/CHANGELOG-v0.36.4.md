# v0.36.4 · 手机顶栏收紧、快捷菜单真图标与跟随定位

发布版本：v0.36.4（三端同源，无插件变更）

## 界面

- **手机顶栏标题卡再收紧**（≤760px）：内边距 `4px 10px 4px 6px`、标识块 32px、图标 17px、
  标题 15px，一行放得下「标题卡 + 搜索 + 快捷入口」三件套，不再挤占内容区。
- **快捷入口菜单换真图标**：全部 10 个入口（快速新建 / 命令搜索 / 四象限 / 时间块 / 收件箱 /
  插件中心 / 设置 / 窗口置顶 / 最小化 / 关闭）由汉字/ASCII 字形（＋ ⌕ 四 时 收 拼 设 钉 － ×）
  改为打包内 Font Awesome solid 图标（`faIcon()` 助手 + `.quick-dock-glyph .fa-ic` 样式），
  与插件图标同源，Android WebView 下直接 `<use>` 生效。

## 修复

- **快捷菜单跟随触发按钮定位**（Android 真机反馈）：顶栏组件可拖动换位后，菜单面板原先是
  `position:fixed; right:20px` 写死在屏幕右侧 —— 按钮挪到左边，面板还在右边展开。
  现在每次展开（含窗口 resize 时）都读取触发按钮实际位置，面板左对齐贴着按钮下方弹出、
  视口内钳制；`transform-origin` 同步改为 `top left`。
- **根因修复**：删除旧 `@media(max-width:560px)` 里 `.quick-dock { left:auto !important;
  top:auto !important }` —— 它会压过 JS 内联定位，与 760px 块的 `bottom:auto` 叠加后
  面板纵向失去任何定位，落在文档静态位置（视口外），表现为「点了快捷入口没反应」。
- resize 监听从旧的持久化坐标定位（会把面板拽回老位置）改为跟随触发按钮重新定位。

## 验证

- 22/22 测试通过（`test-android-layout.mjs` 的置顶按钮断言同步更新为 FA 调用）。
- 无头浏览器（Android UA + 390×844）实测三场景：默认顶栏、按钮在右侧展开、
  按钮移到顶栏最左展开 —— 面板均贴按钮下方，零横向溢出。
