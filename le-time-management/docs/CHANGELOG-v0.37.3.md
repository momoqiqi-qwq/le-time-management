# v0.37.3 · 番茄专注提示音改为可见按钮组

## 改了什么

番茄专注插件（0.3.0 → 0.3.1）「提醒设置」面板里的提示音选择，从 150px 宽的 `<select>` 下拉框改成**可见的胶囊按钮组**：

- 7 种内置音效（清脆提示 / 三音铃 / 钟声 / 木琴 / 电子哔 / 急促三连 / 柔和低音）直接平铺在面板里，手机上不展开下拉也能看到全部常见提醒音。
- 点一下即选中并试听；再点一下已选中的音效＝重新试听。
- 选中态高亮：`--deep` 底 + `--on-deep` 文字（深色主题下强调色被提亮，文字用深墨而非白色，保证对比度）。
- 每个按钮 `title` 带音效说明；按钮组下方保留音效说明行（`presetNotes`）。
- 「试听」按钮移到「提示音」行右侧；音量滑块与「自定义音频」导入行不变。

## 为什么改

`<select>` 下拉在手机上不展开时完全看不到内置音效有哪些（用户反馈：「自定义声音按钮可以看到，内置常见提醒声音」）。平铺按钮组让内置音效可发现、可一键试听切换。

## 守卫

`scripts/test-pomodoro.mjs`：

- 版本断言升到 0.3.1。
- 负向断言：插件源码里不允许再出现 `soundSel`（提示音不许退回下拉框；「关联任务」的任务下拉是合法的 `<select>`，不受影响）。
- 正向断言：`syncSoundChips` 选中态同步、按钮组 `flex-wrap`（390px 手机视口可换行）。

22 个测试脚本全部通过。390×844 手机视口（Android UA）浅色 / 深色（night）实拍验证通过，产物在 `output/preview/phone/pomodoro-sound-chips-{light,dark}.png`。
