# v0.42.0 · 个性化配置即时生效，删除「保存样式」按钮

## 改动（shiguang-schedule 3.5.0 → 3.6.0）

「我的 → 课程表 → 个性化配置」页不再需要点「保存样式」：

- **删除「保存样式」按钮**；样式表单不再走提交流程。
- **拖动即生效**：滑块（格子高度 / 圆角 / 间距 / 透明度）`input` 事件实时应用 —— 直接更新
  `.sg` 容器的 CSS 变量与类名（colorful / hide-times / hide-dates），不整页重绘，拖动不打断。
- **开关即生效**：彩色课程块 / 隐藏节次时间 / 隐藏日期切换（`change` 事件）立即应用。
- **自动保存**：滑块拖动期间 400ms 防抖落库；开关切换立即落库；「恢复默认」先清掉挂起的
  防抖保存再写默认值，防止旧值覆盖重置结果。
- 预览卡说明改为「所有修改即时生效并自动保存」。
- 删除旧的「保存后跳回设置页 + 通知」流程。

## 版本

- 应用版本 0.41.1 → 0.42.0（三端同步，package-lock 两处已手改）
- 插件 shiguang-schedule 3.5.0 → 3.6.0（main.js 已由 build-schedule-plugin.js 重新生成）
