# v0.41.1 · 课程表二级页「返回」落错页修复

## 问题

课程表插件的二级页顶栏「‹ 返回」是**写死的目标页**：`subHead(title, backTo='settings')`，
而「编辑课程 / 添加课程」等页面调用时没传返回目标，落到默认的「我的」设置页。
于是「课程管理 → 点某门课编辑 → 点返回」会回到设置页，而不是来时的课程管理列表。

## 修复（shiguang-schedule 3.4.2 → 3.5.0）

- 新增**模式历史栈** `modeStack`：进入子页（settings / courses / tables / style / edit /
  config / edu / schools / adapters / week-picker）时把当前页压栈；主视图 week / today 不压栈。
- 新增 `back` 动作：返回按钮弹出栈顶回到上一页，栈空兜底回周视图；栈深上限 24，防长会话无限增长。
- `subHead` 默认返回目标改为 `back`，所有二级页调用不再写死目标页；「选择学校 / 返回学校列表」
  等自定义文案保留，目标同样走栈。
- 「添加课程」「课程管理点课程编辑」「选择学校」「选择适配器」四个入口统一走 `enterMode()` 压栈。
- 覆盖路径举例：课程管理 → 编辑课程 → 返回 = 课程管理；周视图 → 选择周次 → 返回 = 周视图；
  教务导入 → 选择学校 → 适配器列表 → 返回 = 学校列表。

## 版本

- 应用版本 0.41.0 → 0.41.1（三端同步，package-lock 两处已手改）
- 插件 shiguang-schedule 3.4.2 → 3.5.0（main.js 已由 build-schedule-plugin.js 重新生成）
