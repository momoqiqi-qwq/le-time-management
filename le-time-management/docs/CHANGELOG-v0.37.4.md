# v0.37.4 · 番茄专注提醒面板默认收起

## 改了什么

番茄专注插件（0.3.1 → 0.3.2）「提醒设置」面板改为**默认收起**：

- 面板体（专注/休息开关、音效按钮组、音量、自定义音频）初始 `display:none`，点「提醒设置」行展开，再点收起。
- 收起时该行右侧保留一行摘要：`专注 开 · 休息 开 · 清脆提示 75%`，不展开也能看到当前配置。
- 手机上计时器整屏完整可见，不再被展开的设置面板压到折叠线以下。

v0.37.3 把内置音效做成了可见按钮组，但面板默认展开会占大半屏（用户反馈：「这些设置平常是收起来的」）——收起后按需一键展开，音效按钮依然点开即见。

## 守卫

`scripts/test-pomodoro.mjs`：版本断言升到 0.3.2；新增守卫「提醒面板必须默认收起」（body 初始 `display:none`，禁止 `display:grid` 默认展开）。

22 个测试脚本全部通过；390×844 手机视口实拍确认收起态（`output/preview/phone/pomodoro-reminder-collapsed.png`）。
