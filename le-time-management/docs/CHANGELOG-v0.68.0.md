# v0.68.0 · 竞赛消息三源合一 + RSS 就地读原文 + 微信推送细到单个插件

## 版本号为什么是 0.68.0

工作树里同时压着**四笔**未提交的在建改动，各自带自己的号：`v0.60.1`（竞赛筛选自愈）、
`v0.63.0`（RSS 两处入口）、`v0.66.0`（竞赛多源化），最后一笔微信推送按插件勾选连说明文件都没写。
期间另一会话把三端推到了 **0.67.0**（局域网直连）并已提交，这三个号全被跨过去了。
`package.json` 只能存一个号，按铁律一取下一个空号 **0.68.0** 一次带走四笔：
`package.json` → `sync-version.js` → `package-lock.json` 手改两处。

前三笔的详细说明已经在各自的说明文件里，本笔不重复抄写，只补第 ④ 笔和跨端影响面。

## ④ 微信推送：插件消息从「一个总开关」拆成「按插件勾」

原来推送设置里「插件收集的新消息」是一颗总开关 —— 要么五个源全推，要么全不推。
而 PushPlus 有频次限制，五个源一起开时最容易撞限，且用户没法只留自己真正在意的那一家。

现在拆成**两层判定**：总开关 + 插件级勾选（`pluginPicks`），两层都过才允许入队。

### 勾格里显示哪些源

`SOURCE_SEED` 写死内置五家（学习通 / 警大门户 / 竞赛消息 / RSS 订阅 / 学校通知），
**不等插件抓过东西才冒出来** —— 装好就能勾。显示名优先取 `tide.plugins.list()` 里的正式名，
与侧栏、插件中心一致；取不到才退回种子名。图标复用随包 PNG（`/icons/plugins/<id>.png`），
用户插件没有 PNG 时 `onerror` 退回插头符号。

用户插件也能进来：`rememberSource()` 把广播过 `notice:new` 的陌生 id 记进 `pluginSources` 落盘，
下一次进推送页还在；**第一次广播时立刻重绘勾格**，不用重开页面。

### 老配置的行为不变，这是有意的

`pluginPicks` 为 `null` = 未细分，所有源都推 —— 与 v1.8.1 及以前完全一致，升级不改变现有推送范围。
用户一旦取消过某个插件的勾，就落成显式数组，**此后新出现的消息源不会被默认打开**
（宁可少推一条，也不要在用户没同意的情况下多推一条到微信）。

### 三个「看起来没生效」的坑，都堵在写入路径上

- **广播早于偏好读回**：进应用就抓到新消息时 `state` 还是默认值，会把用户明明勾了的插件当成没勾丢掉。
  现在 `ensurePrefs().then(...)` 先等偏好落地再判勾选。
- **取消勾选后还是收到推送**：队列里可能已经躺着该源的消息。取消勾选时 `pruneQueue()` 一并清掉。
- **没勾的源白占频次额度**：判定放在入队前，`!allowedSource(id)` 直接不入队，而不是发的时候再滤。

### 五个源统一广播同一份载荷

`cppu-notify` / `gx-news` / `rss-reader` / `school-notice` 本笔新增 `notice:new` 广播
（`chaoxing-notify` 早就有），载荷固定 `{ source, sourceName, total, items[{title, time, sender}] }`，
`items` 最多带 5 条。**判「新」不用界面上的已读集合** —— 那个只在点开详情/转提醒时才写，
拿它差分等于每次刷新都把没点开的旧通知重推一遍；改用「上次第 1 页的 id 快照」差分。
首次抓取没有快照时**只记不广播**，否则一登录成功就把整页历史通知推到微信。

**只有 `rss-reader` 与 `school-notice` 新增了 `events` 权限声明**，另外三家早就声明过。

## 跨端影响面

- **Windows / Android**：四笔全部生效。
- **微信小程序**：竞赛消息只有摩课云一个源（`request` 合法域名白名单只放行了它），
  插件页引导文案已明说「切换源与自定义源需在桌面端使用」。
  另有一处必须修的兼容：桌面端多源后条目 id 带上了 `mokeroad:` 前缀（三家 id 都是自增数字必然撞号），
  `data.json` 两端共用，手机端读 `seen` 时先把前缀摘掉再比 —— 否则已读记录全不命中，
  消息整列表复活成 NEW。写回仍写裸 id，桌面端读回来自己补回前缀。
- **无数据迁移**：不动 `letime-data` 的结构，插件偏好新增键都走「缺省即旧行为」。
- **Android 原生层无改动**：`sync-android-native.js --check` 通过。
