# v0.37.8 · 警大通知「校园服务」收起箭头放大加深

## 问题（用户截图反馈）

校园服务栏右上角的收起箭头太小——13px 的灰色小三角（`◂`），和旁边 10.5px 的栏标题差不多大，几乎注意不到。

## 修法（cppu-notify 1.7.1 → 1.7.2）

- 收起箭头单独放大加深：**18px + `--ink-2` 深灰**（原来与「↻ 重新识别」共用 13px 灰），点击区 3×8px padding；
- 「↻ 重新识别」也顺带从 13px 提到 15px（次要操作，仍比收起箭头小一档，保持主次）；
- 手机端不受影响（≤820px 媒体查询里本就有 44px 点击区规则，本轮桌面端改动不与其冲突）。

## 验证

22 个测试脚本全过（test-cppu 版本断言 1.7.2）；`sync-version --check` ✓ 三端一致 v0.37.8；无头实拍展开态确认箭头清晰可见（`output/preview/win/cppu-side-arrow.png`）。
