# v0.37.1 · 插件页顶栏只留名称，使用说明卡片加图标

发布版本：v0.37.1（三端同源）

## 修复

- **插件页顶栏不再显示长简介**（用户反馈：左上角插件名称被裁）：v0.36.3 把插件视图的
  顶栏副标题从裸插件 ID 改成了 manifest.description 全文，桌面标题卡被超长简介撑爆、
  名称行被裁。现在插件视图副标题直接置空，顶栏只保留插件名称；核心视图的短文案副标题
  不受影响。顺带修掉 sub 为空时残留「·」的问题（`· ${sub}` 改为有值才拼分隔符）。

## 界面

- **「插件使用说明」卡片加插件图标**：每张分类卡片标题左侧显示对应插件的
  `/icons/plugins/<id>.png` 图标（30px 圆角），加载失败自动隐藏（兼容无图标的外部插件）。
- plugin-guide 插件 1.1.0 → 1.2.0。
- 附带 sync-plugins 从小程序端同步回的 exam-calendar 样式改动（另一会话的小程序改版同源）。

## 验证

- 22/22 测试通过。
- 无头浏览器实测：guide 11 张插件图标全部加载；番茄专注页顶栏 h1=番茄专注、sub 为空。
