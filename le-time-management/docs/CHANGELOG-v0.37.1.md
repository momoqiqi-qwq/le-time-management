# v0.37.1 · 插件页顶栏只留名称，考试日历卡片不再压字

发布版本：v0.37.1（三端同源）

## 修复

- **插件页顶栏不再显示长简介**（用户反馈：左上角插件名称被裁）：v0.36.3 把插件视图的
  顶栏副标题从裸插件 ID 改成了 manifest.description 全文，桌面标题卡被超长简介撑爆、
  名称行被裁。现在插件视图副标题直接置空，顶栏只保留插件名称；核心视图的短文案副标题
  不受影响。顺带修掉 sub 为空时残留「·」的问题（`· ${sub}` 改为有值才拼分隔符）。

- **考试日历列表行文字互相压住**（用户反馈 + 截图）：`.ecal-row` 原本是三列 grid
  `112px minmax(0,1fr) auto`，右列 `auto` 里的「倒计时 + 排进日程 + 公告」全是
  `white-space:nowrap` 不可压缩，手机上面板内容盒只有 328px，于是：
  - 中列 `minmax(0,1fr)` 被压到 **0 宽**（第 2 行起实测 0px，第 1 行仅 26px）；
  - `.ecal-bcol` 只有 `min-width:0`、没有 `overflow:hidden`，里面的 nowrap 文字
    直接**画出盒子外**，视觉上糊到右侧倒计时上——这就是「文字重叠」的真身；
  - 实测 17/17 行的考试名被截，最窄只剩 14px（一个「全…」）。

  实测账：日期列实际只需 87px（却写死 112px）＋ 两个 12px 间隔 ＋ 操作列最多 226px
  = **337px > 328px，一行物理上装不下**，所以不是「调调宽度」能解决的，必须换行。
  改成 flex-wrap 两行布局：第一行「日期 + 考试名」，第二行「倒计时 + 按钮」右对齐。

  | 实测项 | 改前 | 改后 |
  |---|---|---|
  | 考试名可用宽 | 14 ~ 26px | **210 ~ 212px** |
  | 考试名被截行数 | 17 / 17 | **3 / 17**（仅最长的「普通话水平测试（PSC）· 下半年各省分批」） |
  | meta 行被截行数 | 17 / 17 | **0 / 17** |
  | 行高 | 55px | **96 ~ 98px** |
  | 文字画出盒子 | 有 | **0**（`.ecal-bcol` 加 `overflow:hidden` 兜底） |

  三处配套改动：
  1. 日期列 112px → `--ecal-date-w:92px`（量出只需 87px），把 20px 还给考试名；
  2. **类型标签（口试 / 准考证打印 / 分批报名…）从考试名同行移到 meta 行首**：
     标签最宽 72px，跟最长 239px 的考试名抢同一行时会把名字挤到 134px 只剩 9 个字，
     而「准考证打印」这类标签本来就和考试名重复（名字里已写着「准考证打印」）；
  3. 「日期 + 主体」包进 `.ecal-main` 再整体换行：否则 360px 宽时
     `92 + 200 + 12 = 304 > 可用 298`，flex 会把主体整列挤到第 2 行、日期孤零零占一行，
     行高从 96px 暴涨到 143px（实测）。

  宽屏单行布局不变（1440px 下考试名 757 ~ 845px，仍是一行到底）。
