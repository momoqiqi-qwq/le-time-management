# Le时间管理 v0.40.0

> 上一版：v0.39.0（顶栏小框回归并跟随视图 + 二级页顶栏并一行 + 课表格子高度拉长 + 课程块左侧竖边删除）

> 新增 **插件使用说明 / 微信提醒推送 / 竞赛消息雷达 / 学习通** 四个原生页面。

## 本版内容

### 背景

此前小程序端只有番茄专注、周度报告、中国节假日、考试日历 4 个原生插件，
学习通、竞赛雷达、微信推送、插件说明等在插件中心里标记「暂不可用」。
本版把其中可落地的一半移植为小程序原生页面，其余（网页收集、学校通知网站）因小程序
合法域名白名单机制**无法请求任意域名**，保持不可用状态并在下文说明原因。

### 新增 1：插件使用说明（plugin-guide 1.2.1 → 1.3.0）

- 静态文档页：分组与使用步骤与桌面端 `plugin-guide/main.js` 同一份内容。
- 每张卡片实时读取插件清单显示版本号与三端平台能力，标「原生适配」的可直接打开。
- 桌面端的「打开外链」按钮在小程序里降级为**复制仓库地址**。

### 新增 2：微信提醒推送（wechat-push 1.3.0 → 1.4.0）

- PushPlus 主通道 + Server酱 兼容，凭据 / Topic / 提前分钟与启停开关存储键与桌面端一致。
- **推送检查范围如实降级**：小程序内只在插件页打开期间每分钟检查一次
  （桌面端是常驻定时器）；时间块提醒与任务截止提醒的去重键、7 天清理逻辑与桌面一致。
- 「一键获取 Token」「官方文档」在无 `openUrl` 能力的小程序里改为复制链接。

### 新增 3：竞赛消息雷达（gx-news 0.1.0 → 0.2.0）

- `wx.request` 抓取摩课云公告（`gxxsjs.com/prod-api`），分页 / 去重 / 类型打分逻辑与桌面端一致。
- 关键词过滤（防抖）、类型 chip、月份 chip、「只看未读」、NEW 角标、按月分组全部保留。
- 点卡片 → 复制详情链接（小程序不能直接打开外站）；「提醒」按钮用小程序同源的
  `timeParser.parseWhen` 识别日期时间，建任务 + 时间块，无日期时落到象限池。
- 桌面端的封面图与 10 分钟自动刷新未移植（封面是外站图片域名，自动刷新对常驻定时器无意义）。

### 新增 4：学习通（chaoxing-notify 2.6.0 → 2.7.0，本版最大改动）

- 纯逻辑抽到 `miniprogram/core/chaoxingCore.js`（可被 Node 测试覆盖）：
  通知归一化 / 分类（考试、作业、签到、通知）/ 截止时间识别 / 链接打分 / 作业附件
  Base64 解析 / 课程学期推断 / Cookie 合并 / **纯 JS DES-ECB-PKCS5**（密码加密必需，
  与本机 Python pyDes 实测向量逐一对照通过，含中文多字节 UTF-8）。
- 登录：账号密码（`fanyalogin`，DES 加密后传输，不明文保存）与 **Cookie 登录**双通道；
  会话 Cookie 手工合并 `Set-Cookie` 响应头（兼容大小写与数组形态）。
- 收件箱：`notice.chaoxing.com` 主路径分页拉取 + 增量去重，NEW 角标、关键词 / 分类 /
  只看未读筛选、本机已读/未读标记覆盖、移除与恢复，存储键（`sessionCookie` /
  `knownIds` / `ignoredIds` / `readOverrides` / `inboxCache` / `filter` / `workStatus`）
  与桌面端**完全同名**，备份 JSON 跨端导入后登录态与已读标记互通。
- 待办作业：截止时间倒排，「正在批改」徽标沿用桌面端的作业页标题探测（串行最多 6 条防风控）。
- 课程页：按学年分 tab + 学年内按完成状态三色分组（红未完成 / 蓝正在进行 / 绿已完成），
  年级按班级名投票出的入学学年推算——推断性质在页面上如实说明。
- 分享码查询：32 位 idCode 或分享链接直接查全文，可转提醒。
- **存储上限适配**：wx 单 key 1MB，收件箱缓存只留最近 300 条且 `raw` 仅保留正文相关
  字段（桌面端缓存 2000 条全量 raw 在小程序必然写盘失败）。

### 明确不做（及原因）

| 插件 | 原因 |
|---|---|
| 网页收集 web-collector | 需请求**任意** URL 读标题/favicon，小程序合法域名白名单不允许 |
| 学校通知网站 school-notice | 同上，任意高校 CMS + 会话登录无法在白名单模型下工作 |
| 警大门户 cppu-notify | SSO 链路复杂 + 验证码 OCR 无原生能力（下批评估「手动输验证码」降级方案） |
| 课程表 shiguang-schedule | 周视图 DOM → WXML 整体重写，工作量大，列入下批 |

### 影响端

- 微信小程序：上述四个插件页 + `pages/plugins` 插件中心徽标（native 数 4 → 8，自动跟随清单）。
- 桌面 / Android：仅 `manifest.json` 的 `platforms.miniprogram` 字段与四个插件版本号变化，
  经 `tools/sync-plugins.js` 重新同步，行为无任何变化。

### 数据迁移

无结构性迁移。插件 storage 键与桌面端同名，旧备份导入即用；
新登录信息按「保存登录信息」开关写入本机（等同账号身份，勿外传备份 JSON）。

## 四、勾开关全量改滑块开关（桌面 / Android 界面统一）

应用本体在 v0.38/v0.39 已把设置页与任务抽屉换成滑块，本节把**剩余散落的勾选框开关**一并清零，
桌面与 Android（同源 WebView）自动生效：

| 位置 | 改动 |
|---|---|
| 番茄专注 · 提醒面板（通知 / 声音 ×4） | `input[type=checkbox]` → `.switch` 滑块（`role="switch"`），版本 0.3.2 → **0.4.0** |
| 收件箱 · 自动化规则启用开关 | 勾选框 → `toggleSwitch` 滑块，样式沿用 `.automation-rule` 行布局 |
| 学习通 chaoxing-notify ·「只看平台未读」「保存登录信息」 | → `.switch` 滑块（搭本批 2.7.0 的版本号） |
| 微信推送 wechat-push · 启用 / 时间块提醒 / 任务截止提醒 ×3 | → `.switch` 滑块（搭本批 1.4.0 的版本号） |

修复：chaoxing `.cx2 input{width:100%}` 与 wechat-push `.wp-field input{width:100%;height:38px}`
两处插件本地样式特异性（0,1,1）压过全局 `.switch`（0,1,0），会把滑块拉成整行蓝条——
均改为 `input:not(.switch)` 排除滑块（实景截图回归验证）。

不改语义：多选型勾选框（批量选择、导出范围）保持原生 checkbox，不属于「开关」。
