# v0.44.0 · Windows 课程表适配触控板 / 触控屏手势（捏合缩放 + 平移）

> 上一版：v0.43.1（学校通知插件读取失败原因持久可见 + session 调用纳入看门狗）

## 背景

课表改成「1–10 节一屏显示」后，行高由剩余空间平分 —— 1440×900 下每行 58px，
课程名字号只有 12px 左右，课程名一长就被截断。用户希望在 Windows 上
**用触控板捏合放大课表**，而不是只能滚动。

## 实现

### 1. 两条捏合路径都要接（Chromium 里不是同一条）

| 设备 | 事件 | 说明 |
|---|---|---|
| 触控板捏合 | `wheel` + `ctrlKey === true` | 和鼠标 `Ctrl+滚轮` 是同一条路，顺手白送键盘用户 |
| 触控屏捏合 | 双指 `touchmove` 的距离变化 | 需要自己算两指间距比例 |

只接 `wheel` 会让触控屏用户完全没反应；只接 `touchmove` 则触控板无效。

### 2. 平移不自己实现

`.wakeup-scroll` 本身就是 `overflow:auto`，原生触摸 / 触控板滚动的惯性、边缘回弹
都比手写好。只加 `touch-action:pan-x pan-y` 显式声明「平移交给原生」，
同时**关掉浏览器自己的捏合缩放** —— 否则双指缩放会去缩放整个 WebView 页面。

### 3. 缩放锚点 = 手势中心

缩放前后，手势中心那个点对应的内容必须停在原地，否则内容会从手指底下跑掉
（用起来像「越捏越偏」）。锚点取**滚动内容里的相对位置**，不是绝对内容坐标。

### 4. 缩放不用 CSS `zoom`（踩坑，见下）

改成「尺寸 × `--wk-zoom`」：行下限、列宽、表头高、自然行高上限、`min-width`
都乘同一个因子；网格根 `font-size: calc(13px * var(--wk-zoom))`，子元素字号全走 `em`。
改一处即整体缩放。

### 5. 交互细节

- 范围 **0.6× ~ 2×**，超出即钳制；恢复持久化值时也过一遍钳制（旧配置可能越界）。
- **双击复位**到 100%：缩得很小或放得很大之后总得有回头路。
- 比例写进 `settings.timeViewZoom` 持久化，切走视图再回来 / 重启应用都保持；
  手势连续变化期间不弹提示，停手 600ms 后 toast 报一次当前比例。

## 踩坑记录

### 🔴 坑一：`zoom` 属性与 `height:100%` + `1fr` 网格语义冲突

第一版用 `zoom` 缩放，结果**缩小反而让行变更大**（实测 `zoom=0.6` 时视觉行高 60.7px，
比 `zoom=1` 的 58.1px 还高），与直觉完全相反。

原因：`zoom` 元素的**内部可用宽高会被除以 zoom**，而网格是 `height:100%` + `1fr` 铺满容器的
⇒ 容器"变大"了，行自然更胖。`transform:scale` 也不行（不改变布局尺寸，滚动范围不跟着变）。
只能用「尺寸乘因子 + em 字号」。

### 🔴 坑二：锚点不能用绝对内容坐标

网格宽受 `min-width`、高受 `height:100%` / `min-height` 三重约束，缩放**不是纯等比**：
实测 `zoom` 1 → 1.377 时网格宽只放大 1.11 倍（1116 → 1239px），
按绝对坐标算锚点会漂 **67px**，内容明显从手指底下滑走。

改用相对位置 `(scrollLeft + px) / scrollWidth` 后漂移降到 **1px**（非等比也成立）。

### 坑三：改完缩放值要强制一次同步布局

`scrollLeft` 的合法范围由内容尺寸决定，刚改完尺寸时范围还是旧的 ⇒ 直接赋值会被
clamp 到旧范围。中间读一次 `scrollWidth` 触发同步 layout 即可。

## 版本

- 应用版本 0.43.1 → 0.44.0（三端同步，package-lock 两处已手改）

## 影响端

- **桌面（Windows）**：新增触控板 / 触控屏捏合缩放与平移，无数据迁移；
  新增设置项 `settings.timeViewZoom`（缺省 1，读取时钳制到 [0.6, 2]）。
- **Android**：窄屏课表本来就是「按天分组」的列表布局，`.wakeup-scroll` 在 ≤760px 是
  `display:none`，手势代码不生效，行为不变。
- **小程序**：不受影响。

## 测试

- 真浏览器手势验证（CDP，`measure-wakeup-gestures.cjs`）：捏合方向 / 锚点漂移 ≤2px /
  边界钳制 / 普通滚轮放行 / 触屏双指捏合 / 双击复位 / 持久化往返，共 8 项全通过。
- 仓库回归断言（`scripts/test-time-views.mjs` 回归 7）：13 条，覆盖
  `touch-action` / `--wk-zoom` 挂点与默认值 / `passive:false` / `ctrlKey` 判定 /
  禁用 `zoom` 属性 / 子元素 em 字号 / 相对锚点 / 强制布局顺序 / 持久化与钳制。
  **变异测试 11/11 全部捕获**（故意破坏每一处，断言都能报错）。
