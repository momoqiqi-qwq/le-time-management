# v0.36.5 · 插件中心筛选数量进按钮

发布版本：v0.36.5（三端同源，无插件变更）

## 界面

- **筛选按钮内嵌数量**：「全部 / 已启用 / 已停用 / 内置 / 用户插件」五个筛选档各自带计数
  胶囊（`.market-filter-count`，`currentColor` 混色，浅深主题与选中态自动适配）。
  数量跟随当前搜索词实时联动（忽略筛选维度本身），搜索时各档计数同步刷新。
- **删除冗余统计行**：原「N 个插件 · N 个内置 · N 个已启用」（`.market-lead`）与
  筛选钮计数完全重复，整行移除；「显示 N / M」保留（反映搜索结果数）。

## 验证

- 22/22 测试通过。
- 无头浏览器（Android UA + 390×844）实测：默认态五个档位计数正确；
  搜索「提醒」后按钮计数与「显示 5 / 12」联动一致。
