# v0.44.1 · Android 插件页加顶栏返回按钮

> 上一版：v0.44.0（Windows 课程表触控板 / 触控屏捏合缩放）

## 背景

用户反馈：**「apk 点进插件后很多没有返回按钮」**。

## 排查（真机同款环境：390×844 真浏览器实测）

先把 12 个内置插件逐个进一遍，用脚本在页面里找「像返回按钮的可见控件」：

| 插件 | 返回类控件 |
|---|---|
| 课程表 | 1 个，但那是「上一周 ‹」 |
| 中国节假日 | 1 个，是月份「‹」 |
| 其余 10 个 | **0** |

⇒ 插件视图里**确实一个返回按钮都没有**。

再看底栏：`.nav` 有 **16 个 button**，但只有 4 个有实际尺寸
（`x=82 / 157 / 233 / 308`，宽 76px），其余 12 个 `x=0,w=0` —— 被 CSS 隐藏了。

根因在 `styles.css` 的 `@media (max-width: 900px)`：

```css
.plug-list { display: none; }   /* 插件入口收进「插件市场」页 */
```

窄屏把 12 个插件直达入口全收走，底栏只剩 **四象限 / 时间块 / 收集箱 / 插件市场** 四项。
进插件后底栏那颗「插件」虽然会高亮（`shell.js` 里 `id === "market" && activeView.startsWith("plug:")`），
点它也能回市场 —— **但它在文案与图标上都是「插件」而不是「返回」**，
用户没有任何「往回走」的视觉入口。所以这不是死路，是**可供性缺失**。

## 修复

顶栏标题卡左侧加一颗返回按钮（`‹`），只在**窄屏**且**确实有地方可回**时出现。

### 为什么不自己实现一套回退

Android 返回键的逻辑已经在 `src/backNav.js` 里（浮层优先、程序性重渲染不压栈、
空格子回收……）。按钮直接复用同一个入口：

```js
onclick: () => goBack()      // backNav.js 里 goBack() = history.back()
```

`history.back()` 触发的 `popstate` 走的就是 `onPopState`，与按硬件返回键**完全同一条路**。
自己写一份「上一个视图」的栈迟早会和它不一致（实测回归测试就是按这条守的）。

### 怎么知道「有地方可回」

WebView 里拿不到可靠的历史长度，所以 `backNav.js` 自己记账：

- `pushState()` 里 `depth++`（压一格）；
- `onPopState()` 里 `depth--`（不管这一格是视图格还是浮层格，popstate 都消耗一格）；
- `initBackNav()` 里归零（热重载 / 宿主重建）。

对外只暴露 `canGoBack()` 与 `goBack()`。**首屏且无浮层时 `canGoBack()` 为 false ⇒ 按钮不出现** ——
那种情况下返回等于退出应用，给按钮反而误导。

### 两处容易写错的顺序

1. **`syncBackButton()` 必须排在 `noteViewChange()` 之后**。`commit()` 早于 `noteViewChange()` 跑，
   而压栈发生在 `noteViewChange()` 里 ⇒ 放前面会慢一拍（表现：刚进插件时按钮不出现，要再切一次才冒出来）。
2. **`popstate` 监听必须注册在 `initBackNav()` 之后**。关浮层这类回退不走 `commit()`，
   得单独补一个监听刷新按钮；注册晚了会读到旧的 `depth`。

## 版本

- 应用版本 0.44.0 → 0.44.1（三端同步，package-lock 两处已手改）

## 影响端

- **桌面（≥901px）**：**完全不受影响** —— `.topbar-back` 基础态 `display:none`，
  实测 1440 / 1100 / 901 三档「可见=false，宽=0」。桌面有侧栏直达全部视图，不需要它。
- **Android / 窄屏（≤900px）**：新增顶栏返回按钮，触控区 40×40px，无数据迁移。
- **小程序**：不受影响（微信自带导航栏有返回）。

## 测试

- 真浏览器实测（390×844，CDP）：首屏不显示 → 进插件显示（40×40 @ 19,7）→ 点击回市场且按钮消失；
  `history.back()` 等效；「市场→插件A→插件B→返回→返回」逐步正确；浮层开着时点返回先关浮层、不切视图。
- 断点实测：1440/1100/901 不可见；900/768/390 可见 40px，标题卡宽 114→154px 自适应。
- 仓库回归：`scripts/test-back-nav.mjs` 新增 4 个行为场景（含热重载归零）+ 一段静态接线断言
  （按钮挂点、调用顺序、`popstate` 注册时机、CSS 断点必须与 `.plug-list{display:none}` 同进退、触控区 ≥40px）。
  **变异测试 15/15 全部捕获。**
