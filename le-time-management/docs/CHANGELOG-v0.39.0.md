# Le时间管理 v0.39.0

> 上一版：v0.38.2（插件页底部空白收窄 + 课程表「我的」条目加图标 + 顶栏标题小框删除）
>
> 本版含三处改动：**顶栏标题小框回归（紧凑版），图标跟随当前视图**；
> **插件二级页顶栏把「返回」与标题并成一行**；
> **课程表删掉底部操作提示行，并按用户设定的格子高度真正拉长。**

## 本版内容

### 背景：那颗小框的一波三折

顶栏标题卡左侧原有一颗 42×42 的圆角小框，里面**恒装** Le 的四象限应用图标 ——
在插件页里（比如「竞赛消息」）跟插件毫无关系，纯属噪音，v0.38.2 应用户反馈整颗删除。

随后用户看了一眼实际效果，回头表示：**框还是想要的，但要小，而且图标得跟插件走。**

### 本版方案

小框回归，规格全换：

| 项 | v0.38.2 之前（旧框） | v0.39.0（本版） |
|---|---|---|
| 尺寸 | 42×42px（顶到标题卡外） | **22px**，窄屏 **20px**（首版 28/24，用户复核后再收一档） |
| 高度观感 | 高于标题两行文字 | 低于标题两行，稳稳落在顶栏两条横线之间 |
| 图标来源 | 写死的 Le 应用图标 | **跟随当前视图**：插件页装插件自己的图标（竞赛消息 = 奖杯，课程表 = 课表……），核心页装各视图导航图标（四象限 / 时间块 / 收件箱 / 插件中心） |
| 用户自定义图标 | 不跟随 | 跟随（走 `pluginDisplayIcon`，设置里换过的图标照常生效） |
| 底色 | 固定 | 跟随插件强调色（与插件中心卡片同一套 `--plugin-accent` 配方） |

### 影响端

- Windows 桌面端：顶栏标题卡左侧出现紧凑小框。
- Android：同上；窄屏用 24px 规格，标题卡整体高度不变（顶栏 50px 内照旧装得下）。
- 小程序：无此顶栏结构，不受影响。

### 数据迁移

无。纯 UI 改动，不触碰存储结构与插件数据。

### 回归断言

`scripts/test-android-layout.mjs` 里 v0.38.2 的「负向断言」（不许有小框）已改写为
v0.39.0 的正向断言：小框必须存在、尺寸必须在 20~30px 之间且为正方形、内部 `.app-icon`
必须有尺寸规则、插件页必须装 `pluginDisplayIcon`、不许再恒装四象限应用图标。
标题卡内边距左右对称的断言保留不变。

## 附：插件二级页顶栏「返回 + 标题」并成一行（插件 3.4.2）

### 背景

用户截了一张 1305×157 的长条，说「设置里面还有插件里面一些界面，莫名占的位置太多又很空」。
截图是暗的（整幅亮度只有 11~55）且文字比底色还暗，看不出是什么；于是按字形反查：
3 个字形匹配到「‹ 返回」，5 个字形匹配到「个性化配置」—— 确认是
**时光课程表「我的 → 个性化配置」**子页的顶部。那 157px 里 47px 是纯空白、38px 给了返回按钮、
17px 还是空白，真正的内容一行都没有。

根因不在某一页，而在所有二级页共用的 `subHead()`：

```
<div class="back-row">‹ 返回</div>              ← 独占一整行，按钮 min-height:38px
         ＋12px 外边距
<div class="screen-head"><h2>标题</h2></div>     ← 另起一行，再吃 4px 上边距
```

叠上 `.plugview` 的 20px 与 `.sg` 的 20px 内边距，**正文要到距顶栏 140px 处才开始**。

### 改法

`subHead()` 改成输出单个 `.screen-head.sub-head`：返回按钮与 `<h2>` 同处一行、间距 8px。
`.sub-head` 用 `justify-content:flex-start` 压掉 `.screen-head` 的 `space-between`
（否则标题被顶到最右端），并复用原来 `.back-row` 的无边框观感，行高由 38px 的按钮撑起。
签名扩成 `subHead(title, backTo='settings', sub='', backLabel='‹ 返回')`，
把原先手写两行的「选择学校」「适配器列表」两页也一并收编 —— **共 10 个二级页走同一套**。

### 实测（无头 Chrome，真 CSS 真视口）

| 视口 | 顶栏区高度 | 正文距顶栏 | 横向溢出 / 越界元素 |
|---|---|---|---|
| 1280×900 · 深色 | 82px → **38px** | 140px → **92px** | 0 / 0 |
| 390×844 · 深色 | 82px → **38px** | 120px → **72px** | 0 / 0 |

**省 48px，正文起始位置前移 34%。** 返回按钮与标题的垂直中线偏差 ≤2px（确实同一行）、
按钮整体位于标题左侧；点返回按钮仍能回到「我的」，7 个条目齐全；文字与背景色值前后完全一致
（本次只动几何，不碰配色）。

### 影响端

三端同源（`public/plugins/` → 桌面 / Android / 小程序插件目录），**插件版本 3.4.1 → 3.4.2**。

### 数据迁移

无。纯 UI 改动。

### 回归断言

`scripts/test-schedule.mjs` 新增一节，把 `subHead` 挂进 vm fixture 后**钉渲染出来的结构**：
只能渲染一个顶栏、必须带 `sub-head` 修饰类、返回按钮在 `<h2>` 之前、**从顶栏开头到 `<h2>` 之间
不许出现 `</div>`**（这条最硬：退回两行结构必然冒出 `</div>`）、副标题与自定义返回目标/文案都要生效、
源码里不许再留 `back-row`、`.sub-head` 必须写在 `.screen-head` 之后且把 `space-between` 改成
`flex-start`。变异测试 **10/10** 全部被对应断言拦下。

## 三、课程表：删掉操作提示行，课表真正拉长

用户反馈：那行「左右滑动切换周次，点击课程查看或编辑；更多操作见右上角「⋯」」
是句废话（滑动与点击本来就会用），删掉；同时课表再拉长一些。

### 删掉提示行

`weekContent()` 里那行 `.schedule-note` 连同它的两条样式规则（基础 + ≤620px）一起清除，
不留死代码。

### 课表为什么之前拉不长

宽度 ≤900px 时有一条 `.sg .main-stage{min-height:0}` —— 它把课表容器的高度下限**取消了**，
于是 `.schedule-frame`（`flex:1 1 0`）只能吃到「顶栏与底部导航之间的剩余空间」：

| 390×844 实测 | 修前 | 修后 |
|---|---|---|
| `.schedule-grid` 高度 | 596px | **736px** |
| 单行高度 | 55.6px | **69.6px** |
| `.schedule-frame` | 598px | 738px |

注意 **55.6px 远低于用户设定的 `--sg-slot-height`（默认 76px）** —— 也就是说
「个性化配置 → 课表格子高度」这个滑杆在手机上一度是**失效的**：调到 120 也不会更高。

**修法**：把那条 `min-height:0` 换成一个跟着节次数走的真实下限：

```css
@media (max-width:900px){
  .sg .main-stage{ min-height: calc(var(--sg-head-h,52px) + var(--slot-count,10) * var(--sg-slot-height,76px) + 2px) }
}
```

这样格子高度滑杆在手机上真正生效；一屏放不下时由外层 `.plugview` 正常滚动
（实测可滚动 132px，滚到底后署名底边 782、底栏顶边 791 ⇒ 净余 9px，无遮挡）。
桌面端（>900px）走自己的 `min-height:520px`，不受影响（1280×900 实测网格仍 636px）。

### 回归断言（变异测试 3/3 被拦下）

`scripts/test-schedule.mjs` 新增两条：
① 窄屏 `.main-stage` 必须用 `calc()` 按节次数给下限，且**不许再出现 `min-height:0`**；
② 源码里不许再残留 `schedule-note`（标记或样式）。

变异验证：改回 `min-height:0` → 拦下；把提示行加回来 → 拦下；改成固定 `min-height:300px`
（脱离节次数）→ 拦下。验完已还原（`ui.js` sha256 与备份逐字节一致）。
