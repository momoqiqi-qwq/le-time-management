# v0.37.10 · 学习通卡片「标记」按钮 + 彩色框

## 改了什么（chaoxing-notify 2.5.1 → 2.6.0）

1. **彩色框**：每张通知卡的左边框按类型着色，与分类标签同色系——通知=主题色（deep）、作业=橙（sun）、考试=红（coral）、签到=绿（mint）。原来只有未读卡有青色左边框、已读卡全素；现在所有卡都有归属色。
2. **未读标识改底色微染**：`unread` 卡的青色左边框让位给类型色，改为海青 7% 底色微染，未读依然一眼可辨。
3. **「标记」按钮**：每张卡新增「标记已读 / 标记未读」（海青色框），走本机 `readOverrides` 覆盖（id → true=未读/false=已读，上限 1000 条），只影响本机显示、筛选（「只看平台未读」改为按有效未读过滤）和顶部「未读」KPI（原「平台未读」），**不动学习通服务端的已读状态**。按钮文案随当前状态切换。

## 说明

- 「删除」需求由卡片上已有的红色「移除」按钮承担（仅从本机列表移除、可一键恢复，不影响平台数据），按插件文案约定不叫「删除」。
